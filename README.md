# ma-deal-design · 并购交易全流程专家问答

由资深并购从业者构建的并购交易知识服务,覆盖:**标的筛选 · 交易结构设计 · 估值建模 · 尽职调查 · 商务谈判 · 交易文件起草(TS/SPA) · 私有化 · A股并购重组 · 国企整合 · 矿业/跨境JV · PE/LBO · 困境重组 · ABS**

## 怎么用(两种方式)

### 方式一:网页提问(推荐,零安装)

1. 点击本仓库顶部 **Issues** 标签页
2. 点绿色按钮 **New issue**,标题写一句话问题,正文补充你的交易背景(交易类型/买方还是卖方/大概阶段)
3. 提交后机器人会在 **1-2分钟内**基于作者私有知识库生成结构化专家分析

> 示例提问:"港股H股私有化有哪几种结构?各自通过门槛和失败风险?"
> 免费服务,每位用户每日3个提问。深度问题(具体交易方案设计)建议写清背景,回答质量更高。

### 方式二:本地安装lite版skill(配合AI编程助手使用)

将本仓库 `skill/` 文件夹下载后,复制到你AI助手的技能目录(如 `~/.agents/skills/ma-deal-design/`),即可在助手对话中获得通用并购方法论支持(NDA审查/尽调清单/风险分级/时间表/可研/PMO/投后整合),并自动引导深度问题到Issues服务。

## 内容与更新

- 知识库持续跟踪市场与法规更新(如2025年12月《商业银行并购贷款管理办法》金规〔2025〕27号新规)
- 更新即生效:无需重新安装,下次提问自动使用最新知识
- 知识库内容为作者私有资产,服务仅提供场景化分析,不提供文档原文下载

## 服务边界与免责

- 回答由AI基于作者知识库生成,仅供学习与决策参考,**不构成法律意见、税务意见或投资建议**;重大决策请咨询持牌专业人士
- 所引法规可能存在时效性,使用前请核实现行有效性
- 本仓库及其问答服务内容受《中华人民共和国著作权法》保护,未经作者书面授权,禁止转售、捆绑销售、商业培训及批量抓取转存
