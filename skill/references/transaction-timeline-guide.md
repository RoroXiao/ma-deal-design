# 交易时间表生成指南

> **适用场景**：六种交易类型的全流程时间表编制（跨境股权收购/上市公司要约/私有化/JV/资产收购/PE退出）——关键节点、依赖关系、审慎buffer。**核心受众**：交易PMO、投行执行层。**使用方法**：选择交易类型模板 → 填入具体日期 → 识别关键路径 → 标注审批buffer。
> **核心受众**：投行项目组、企业投资部门、FA、律师事务所。
> **输出标准**：周维度甘特图 × 工作流维度责任矩阵，可直接用于项目启动会。

---

## 1. 时间表在并购流程中的定位

时间表是项目管理的"指挥棒"。一份好的时间表不只是排日期，而是：

- **识别关键路径**：哪些工作流是串联的（后一步必须等前一步完成），哪些可以并联推进
- **明确责任分工**：每个节点的责任方（买方/卖方/FA/律师/会计师/评估师）
- **预判瓶颈**：监管审批、内部决策、假期窗口等可能拖延进度的环节
- **倒排驱动**：从目标签约日或交割日倒推，确保各条线按时汇合

---

## 2. 通用工作流框架（8条线）

所有并购交易的时间表都可以分解为以下8条工作流，不同交易类型的权重和顺序略有差异：

| 编号 | 工作流 | 核心内容 | 典型责任方 |
|:---:|--------|---------|-----------|
| A | 项目管理 | 组建团队、建立通讯录、例会机制、定期汇报 | 综合组/FA |
| B | 尽职调查 | 尽调清单、现场走访、访谈、出具报告（法律/财务/业务/技术） | 各中介机构 |
| C | 交易结构 | 方案设计、对价分析、架构搭建、协同效应 | FA、律师 |
| D | 法律文件 | SPA/SHA/章程等起草、谈判、定稿 | 律师 |
| E | 内部审批 | 投委会→党委会→总办会→董事会→股东会（央企多层级） | 买方内部 |
| F | 外部审批 | 国资委备案/反垄断/发改委/商务部/外管局/证监会 | FA、律师 |
| G | 信息披露 | 权益变动报告、预案、草案、问询回复（上市公司适用） | 上市公司+FA |
| H | 资金安排 | 融资方案、并购贷款、资金调拨、外汇 | 买方财务部 |

### 2.1 工作流间的依赖关系

```
A 项目管理 ──────────────────────────────────────────→ 贯穿全程
                    ↓
B 尽职调查 ──────────────→ 出具报告初稿 ──→ 报告终稿
                              ↓                    ↓
C 交易结构 ←── 基于尽调发现 ──→ 确定方案
                              ↓
D 法律文件 ←── 基于交易结构 ──→ 起草初稿 ──→ 谈判 ──→ 定稿
                                                      ↓
E 内部审批 ←── 需要尽调报告+可研结论 ──→ 投委会 ──→ 董事会 ──→ 股东会
                                                              ↓
F 外部审批 ←── 需要交易文件 ──→ 国资委 ──→ 反垄断 ──→ 证监会
                                                        ↓
G 信息披露 ←── 配合各节点 ──→ 预案 ──→ 草案 ──→ 问询回复
                                                        ↓
H 资金安排 ←── 需要投资估算 ──→ 融资审批 ──→ 资金到位 ──→ 付款
                                                              ↓
                                                         交割 (D-Day)
```

### 2.2 串联 vs 并联

| 关系类型 | 含义 | 示例 |
|---------|------|------|
| **串联** | B必须等A完成才能启动 | 国资委评估备案必须在土地房产瑕疵解决后才能申报 |
| **并联** | A和B可同时推进 | 审计报告与法律尽调可并行 |
| **条件触发** | B的启动取决于A的结论 | 交易结构设计依赖尽调初步发现 |

**关键路径上的串联环节决定了项目最短工期。** 优化时间表的核心是尽可能将串联改为并联。

## 3. 六种交易类型的标准时间表模板

### 3.1 跨境股权并购（央企/国企）

**典型工期**：6-12个月（签约前4-8个月 + 签约后2-4个月交割）

```
阶段一：尽调与方案（T-16周 ~ T-4周）
  Week 1-2:  A1 组建项目组    B1 发出尽调清单    C1 初步方案分析
  Week 3-4:  B2 现场尽调      B3 管理层访谈      A4 启动例会机制
  Week 5-6:  B4 出具报告初稿   C2 交易结构细化    D1 法律文件初稿
  Week 7-8:  B5 报告终稿      C3 确定交易结构    D2 开始谈判
  Week 9-10: D3 法律文件定稿   E1 投委会审议     H1 融资方案确定
  Week 11-12: E2 党委会/总办会  H2 资金准备      F1 国资委预沟通

阶段二：审批与签约（T-3周 ~ T）
  Week 13:   E3 董事会审议    F2 国资委正式申报
  Week 14:   E4 股东会通知    F3 反垄断申报
  Week 15:   E5 股东会审议    D4 交易文件终稿
  Week 16:   T 签署SPA

阶段三：交割（T+1 ~ T+12周）
  Week 17-20: F4 获取外部审批   H3 资金到位
  Week 21-24: F5 证监会审核（如涉及上市公司）
  Week 25-28: D 交割           工商变更登记
```

**央企特有节点**：投委会→党委会→总经理办公会→董事会（四级决策链，通常需2-3周）

### 3.2 上市公司控制权转让（协议受让）

**典型工期**：4-8周（签约前倒排，签约后4-8周过户）

```
T-15天:  确定投资主体、确定资金方案
T-12天:  交易条款清单谈判、资料需求清单发出
T-10天:  交易协议初稿、简式权益变动报告书初稿
T-7天:   协议定稿、信息披露文件定稿
T-5天:   履行内部审批及签署前置程序
T:       签署股权转让协议 + 上市公司发布权益变动公告
T+1:     向交易所提交合规性审查
T+3:     取得交易所合规性审查确认
T+5:     完成股票账户开立
T+10:    转让方完成股票解质押
T+15:    取得交易所合规确认 → 申请股份登记变更
T+19:    中登完成股份登记变更
T+20:    上市公司发布过户完成公告
```

**关键约束**：深交所/上交所协议转让需纸质原件，中登受理及办理过户时间存在不确定性（法定办结时间为受理后3-5个工作日）。

### 3.3 上市公司定增（向特定对象发行股份）

**典型工期**：3-5个月（预案到核准）

```
阶段一：预案阶段（Week 1-4）
  W1:     各中介机构完成立项
  W2:     董事会全套文件起草
  W3:     尽调清单发出、资料收集
  W4:     董事会审议预案【A】+ 暂不召开股东大会通知

阶段二：补充尽调与准备（Week 5-8）
  W5:     公司反馈尽调资料、确定审计基准日
  W6:     补充尽调、豁免承诺文件（如涉及）
  W7:     董事会审议豁免事项【B】
  W8:     股东大会通知【B】+ 国资批复（如涉及）+ 反垄断审批

阶段三：发行准备（Week 9-12）
  W9:     股东大会审议豁免【B】+ 董事会审议改组【C】
  W10:    申报材料初稿 + 中介内核程序 + 股东大会通知【C】
  W11:    股东大会审议改组【C】+ 董事会审议预案修订【D】
  W12:    股东大会审议发行议案【D】+ 申报材料签字

阶段四：审核与发行（Week 13-20）
  W13:    首次申报报送交易所
  W14:    交易所受理
  W15-16: 交易所问询 → 组织答题
  W17-18: 提交问询回复
  W19-20: 获取核准/注册 → 发行
```

### 3.4 国企重组（资产注入/置换）

**典型工期**：8-12个月（预案到核准）

```
阶段一：预案准备（Month 1）
  M1W1:   持续落实重组方案、识别重点问题（土地房产瑕疵、关联交易等）
  M1W2:   准备一次董事会预案披露文件
  M1W3:   与国资委预沟通、与证监会预沟通
  M1W4:   召开第一次董事会，公告预案并复牌

阶段二：尽调与审计（Month 2-3）
  M2:     中介机构持续尽调、审计评估工作
  M3:     土地房产瑕疵处理、资产剥离
  M3末:   置入/置出资产审计评估定稿

阶段三：草案与国资备案（Month 4-5）
  M4W1:   准备二次董事会重组报告书
  M4W3:   完成国资评估备案
  M4W4:   上市公司完成年报审计 + 标的资产加期审计
  M5W1:   召开第二次董事会，公告交易报告书草案
  M5W2:   向国资委提交正式申请 + 反垄断申报
  M5W3:   获得国资委正式批复
  M5W4:   召开股东大会审议通过

阶段四：证监会审核（Month 6-8）
  M6:     向证监会提交申请材料
  M6-7:   收到反馈意见并回复 + 更新331基准日审计
  M8:     通过并购重组委会议 → 取得核准批文

阶段五：交割（Month 9）
  M9W1:   完成资产交割与新股发行上市
  M9W2:   募集配套资金（如涉及）
```

**央企重组的四大制约因素**：
1. 土地房产瑕疵解决 → 国资委备案的前置条件（串联）
2. 国资委评估备案 → 需2-3个月
3. 年度审计报告 → 需与年报审计衔接（并联）
4. 证监会审核 → 不可控因素较多

### 3.5 JV合资设立（跨境）

**典型工期**：6-9个月（JVA签署到JVCO成立）

```
阶段一：JVA签署前（Week 1-3）
  W1:     确定JVCO名称、注册资本
  W2:     内部投资决策（投委会/IC）
  W3:     董事会决议授权签字 + JVA小签

阶段二：JVA签署后先决条件（Month 2-6）
  M2:     ODI预沟通（发改委/商务部/外管局）
  M2-4:   ODI正式申报（3-6个月）
  M2-3:   选址决定、土地报价函
  M3:     股东批复、前期成本预算
  M3-5:   DOE（设立契据）起草与公证
  M3-6:   融资方案确定、IP框架协议谈判
  M4-6:   投资方案编制、董事/监事/高管提名

阶段三：JVCO成立（Month 7-9）
  M7:     所有先决条件满足或豁免
  M8:     签署DOE、向相关部门注册
  M9:     JVCO正式成立、启动运营
```

**关键先决条件**：ODI批复、双方股东批复、DOE公证、融资方案、IP框架协议、选址确认。

### 3.6 ABS资产证券化

**典型工期**：2-4个月（申报到发行），按五条通道分别排期

```
申报阶段:
  交易所ABS:    审议通过后20个交易日内提交封卷材料
               有条件通过: 5个工作日内落实条件（可延期10个工作日）
  信贷ABS:     单期批文/额度批文
  ABN:         注册有效期2年，首期发行应在注册后6个月内完成

发行前:
  信贷ABS:     T-10工作日提交人行备案 → T-5发行文件挂网 → T-1申购配售文件挂网
  交易所ABS:   T-5提交代码申请 → T-3提交备案 → T-2提交说明书
  ABN:         收到建议函后10个工作日内提交补充文件

簿记发行:      择机完成

发行完成后:
  交易所ABS:   设立日上传发行结果及成立公告 → 设立日+2登记
  信贷ABS:     发行完成后45个工作日内底稿报送（23个工作日内提交审核员）

存续期:
  交易所ABS:   每年4月30日前完成年度披露
  收益分配:    付息日T-12前预沟通 → T-5前提交收益分配公告

终止清算:      清算完成后10个工作日内披露清算公告
```

### 3.7 外资战略投资人协议受让上市公司股份（多监管并联）

**典型工期**：自签署至交割约 4-5 个月（监管审查为关键路径，实际受交易方案与监管沟通影响）

```
T+0:      签署股权转让协议 + 上市公司公开披露交易公告
T+2周:    临时股东大会审议通过交易议案
T+2周:    提交国家安全审查申报材料；提交反垄断审查申报材料；提交交易所合规审查申报材料
T+2周:    申请证券账户卡
T+5周:    国家安全审查：完成初步审查，启动一般审查
T+11周:   国家安全审查：完成一般审查（工作机制办公室作出决定）
T+13周:   反垄断审查：市场监管总局出具审查决定书；交易所：获得所有外部审查证明文件
T+15周:   国家安全审查：工作机制办公室作出通过决定
T+17周:   交易所：作出通过合规审查决定；完成交割；商务部事后报备
```

**关键约束**：
- 国家安全审查、反垄断审查、交易所合规审查可并联推进，但均须在交割前完成；任一未通过将阻断交割。
- 国家安全审查：外资成为最大外部股东且有权提名董事时，通常进入一般审查（30 个工作日）或特别审查（60 个工作日，可延长）。
- 反垄断审查：参与双方市场影响力较大时预计进入普通审查（初步审查 30 日 + 进一步审查 120 日，可延长）。
- 交割先决条件通常包含上述审查通过及证券登记机构过户登记确认。

## 4. 里程碑节点速查

### 4.1 通用里程碑代号

| 代号 | 含义 | 典型后续动作 |
|------|------|------------|
| T | 签约日（Signing） | 交易协议签署、信息披露 |
| T+N | 签约后N天 | 付款、审批申报 |
| D | 交割日（Closing） | 股权过户、工商变更 |
| D+N | 交割后N天 | 过渡期审计、尾款支付 |
| C | 交割完成日 | 全部交割条件满足 |

### 4.2 各交易类型的关键里程碑

| 交易类型 | 关键节点序列 |
|---------|------------|
| 跨境并购 | 投委会 → 董事会 → 签约(T) → 国资委批复 → 反垄断 → 发改委/商务部/外管局 → 交割(D) |
| 上市公司协议受让 | 内部审批 → 签约(T) → 交易所合规审查 → 中登过户 → 公告 |
| 上市公司定增 | 董事会预案 → 股东大会 → 申报 → 问询回复 → 核准/注册 → 发行 |
| 国企重组 | 一董(预案) → 审计评估 → 国资备案 → 二董(草案) → 股东大会 → 证监会审核 → 核准 → 交割 |
| JV设立 | JVA签署 → ODI → DOE → 注册 → JVCO成立 |

## 5. 时间表编制的实务要点

### 5.1 假期处理

编制时间表时必须考虑中国法定节假日（春节、国庆等）以及交易相关国家的假期。关键原则：

- **春节前后（1月中旬-2月中旬）**：国资委审核速度放慢，需预留buffer
- **国庆（10月1-7日）**：证监会、交易所休假
- **元旦（1月1日）**：年报审计基准日相关节点需注意
- **跨境项目**：需叠加标的所在国假期（如东南亚斋月、欧美圣诞节）

### 5.2 倒排法

从目标日期倒推各节点：

```
目标：2024年6月30日完成交割
  ← D-30:  取得证监会核准批文
  ← D-45:  通过并购重组委会议
  ← D-75:  提交证监会申请材料
  ← D-90:  召开股东大会
  ← D-110: 召开第二次董事会（公告草案）
  ← D-120: 完成国资评估备案
  ← D-135: 审计评估定稿
  ← D-150: 召开第一次董事会（公告预案）
  ← D-165: 启动尽调
  ← D-180: 项目启动
```

### 5.3 关键路径优化

| 优化手段 | 说明 |
|---------|------|
| 并联推进 | 审计与法律尽调同时启动，不等一条线完成再启动另一条 |
| 提前沟通 | 国资委、证监会、交易所的预沟通可在尽调期间同步进行 |
| 压缩内部流程 | 党委会、投委会、总办会尽量紧凑安排（连续3天） |
| 节前冲刺 | 在长假前完成关键节点（如签约），避免假期耽误 |
| 同步审批 | 反垄断申报与国资委审批可并联 |

### 5.4 责任矩阵模板

每个时间表节点应明确以下维度：

| 维度 | 说明 |
|------|------|
| 事项 | 具体工作内容 |
| 交付物 | 完成标志（如"已签署的JVA""审计报告盖章版"） |
| 计划时间 | 目标完成日期 |
| 用时 | 预估耗时 |
| 责任主体 | 主责方（如"FA""律师""买方财务部"） |
| 协助方 | 配合方 |
| 进度状态 | 未启动/进行中/已完成/延期 |
| 备注 | 风险提示、依赖说明 |

## 7. 过渡期管理（从签约到交割的禁止事项与量化阈值）

并购协议签署后至交割完成前为"过渡期"，标的公司价值须基本维持。实务中通常按三阶段管理禁止/限制事项：

- **签约前（签约日至付款前）**：禁止重大资产处置、新增重大债务、异常分红、变更主营业务；经营业绩波动超过约定阈值（如 >5%）须事先书面通知收购方。
- **付款期前**：核心管理人员须留任并签署不竞争/不挖角承诺，留任约束常延续至交割后 120 日或 3 年（视角色而定）。
- **付款后（交割完成前）**：单笔支出超过约定金额（如 >200万）须通知，超过更高金额（如 >500万）须取得收购方事先同意。

**配套机制**：过渡期损益归属条款（收益归收购方、亏损由转让方补足）、重大不利变化（MAC）监控、信息披露同步机制。建议在 SPA 中单列"过渡期承诺"章节并以量化阈值固化，避免交割争议。

## 8. 交割交接工作流（D-Day 后）

交割日（D-Day）后须完成标的资产/实体的实际控制权移交，建议设总协调人 + 专业分组：

- **分组**：法务（合同/诉讼/知识产权）、财务（账簿/银行/税务）、人事（花名册/社保/劳动关系）、IT（系统/U盾/权限）、印章证照（公章/执照/资质）。
- **交接清单（40+ 项）**：营业执照正副本、公章/财务章/合同章、银行 U 盾、账簿凭证、知识产权证书、员工花名册与劳动合同、重大合同清单、未决诉讼清单、资质许可等。
- **专项**：过渡期损益专项审计衔接、交割确认书签署、对价释放节奏（首付款 → 尾款/holdback）。
- 建议以"交接确认单 + 影像留存"双轨留痕，防止交割后权属争议。

## 9. 国资规则速查（外部审批）

涉及国有主体的交易须叠加国资监管规则：

- **核心依据**：32号令（企业国有资产交易监督管理办法）、36号令（上市公司国有股权监督管理办法）、39号文（国有股东转让所持上市公司股份）等。
- **进场交易**：国有产权转让原则上须通过产权交易所公开进行（公开征集受让方 ≥10 个交易日、不得设指向性条款）；非公开协议转让仅限特定情形（如国资内部重组、同一控制下转让）。
- **无偿划转**：适用范围扩大后，国有股权无偿划转须满足主体与程序要求并办理产权登记。
- **评估备案**：国资交易须以经备案的资产评估值为定价参考，评估结果须在有效期内使用。
