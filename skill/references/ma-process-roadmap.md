# 项目启动与机会筛选

> **适用场景**：并购交易从零启动——标的筛选、策略规划、卖方包装、买方寻访的全流程指引。**核心受众**：交易团队负责人、投行MD/VP、企业战略投资部。**使用方法**：先确定买方还是卖方视角，再对照对应流程图定位当前阶段。

---

## 1. 买方视角：全流程与决策节点

### 1.1 买方并购全流程（含 Go/No-Go Gates）

```
┌─────────────────────────────────────────────────────────────────┐
│                    BUY-SIDE M&A WORKFLOW                        │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  Phase 1: 策略与筛选 (Strategy & Sourcing)                     │
│    ├─ 行业研究 + 标的长名单                                    │
│    ├─ Approach 策略设计（主动接触 vs 投标）                    │
│    ├─ 签署 NDA                                                  │
│    └─ ★ Gate 1: 是否值得投入人力做初步尽调？                  │
│         ├─ Go → Phase 2                                        │
│         └─ No-Go → 放弃 / 监控                                 │
│                                                                 │
│  Phase 2: 初步尽调与估值 (Preliminary DD & Valuation)          │
│    ├─ 数据室初步审阅 + 管理层引介                              │
│    ├─ 初步估值范围（DCF / 可比公司 / 可比交易）               │
│    ├─ 发出非约束性报价 (NBO / IOI)                             │
│    └─ ★ Gate 2: 是否进入确认性尽调？                          │
│         ├─ Go → Phase 3 (NBO 被接受后)                         │
│         └─ No-Go → 通知卖方退出 / 转为监控                    │
│                                                                 │
│  Phase 3: 确认性尽调 (Confirmatory DD)                         │
│    ├─ 五个条线并行：法律 / 财务 / 税务 / 商业 / 技术          │
│    ├─ 管理层全面访谈                                           │
│    ├─ 现场考察 + 第三方函证                                     │
│    ├─ 风险分级 → 反向影响交易结构                              │
│    └─ ★ Gate 3: 尽调发现是否超出可接受范围？                  │
│         ├─ Go → Phase 4                                        │
│         └─ Conditional Go → 调整对价/增加赔偿/增加条件先决    │
│         └─ No-Go → 退出                                        │
│                                                                 │
│  Phase 4: 谈判与签约 (Negotiation & Signing)                   │
│    ├─ 谈判 TS / SPA 核心条款                                   │
│    ├─ IC / 董事会批准                                           │
│    └─ ★ Gate 4: 签约前最后一审                                 │
│         ├─ Go → 签约                                           │
│         └─ No-Go → 重新谈判 / 退出                             │
│                                                                 │
│  Phase 5: 审批与交割 (Approvals & Closing)                     │
│    ├─ 监管审批（反垄断/国安/外资/行业）                        │
│    ├─ 融资到位（并购贷款提取）                                 │
│    ├─ 交割条件逐项清除                                         │
│    └─ ★ Gate 5: 所有审批是否就绪？                             │
│         ├─ Go → 交割                                           │
│         └─ Long-Stop → 终止 / 延长 last date                   │
│                                                                 │
│  Phase 6: 投后整合 (Post-Merger Integration)                   │
│    ├─ Day 1 就位（系统/授权/通告）                             │
│    ├─ 百日计划 + 协同效应追踪                                   │
│    └─ 投后复盘 → 经验沉淀                                      │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 1.2 IC 决策节点

| 决策点 | 触发条件 | 决策内容 | 所需材料 |
|--------|---------|---------|---------|
| Gate 1 | 标的短名单确定后、签署 NDA 前 | 是否投入人力做初步尽调？ | 标的画像、行业分析、初步估值范围 |
| Gate 2 | NBO 被卖方接受后 | 是否进入确认性尽调？ | 初步尽调发现、修订估值范围、交易可行性概评 |
| Gate 3 | 确认性尽调完成后 | 尽调发现是否可接受？如调整后是否可继续？ | 尽调报告、风险矩阵、修订后交易结构、TS 草案 |
| Gate 4 | SPA 签约前 | 是否签署？ | SPA 定稿、IC 备忘录、独立法务意见 |
| Gate 5 | 所有审批完成后 | 是否交割？ | 审批文件、融资到账证明、交割条件清除清单 |

### 1.3 Go/No-Go 快速判定标准

| 维度 | Go 条件 | No-Go 条件 |
|------|--------|-----------|
| 估值 | 在 DCF 合理范围内（Even with conservative scenario） | 超出 DCF 上限 +50%，无可靠协同解释 |
| 合规风险 | 审批否决概率 < 20% | 制裁/CFIUS/国安否决概率 > 50% |
| 尽调发现 | 关键风险有缓释方案（earn-out/escrow/indemnity） | 发现系统性问题（核心资产无合法权属、主业违法经营） |
| 竞争格局 | 标的的市场地位可防御 | 行业面临颠覆（技术/监管）且标的无转型能力 |
| 团队 / 整合 | 管理团队可留任或有替代方案 | 关键人员无保留可能且无替代管理能力 |
| 融资可行性 | 银行/融资方已出具非约束性承诺 | 融资缺口 > 交易对价 30%，无替代融资路径 |

> **首条纪律**：设立投资委员会（IC）并严格执行 Gate 机制。不在 Gate 获得通过前推进下一阶段，避免"沉没成本谬误"——"我们已经投入这么多时间/费用，不能退"→ 这正是应该退的时候。

## 2. 卖方视角：交易流程与买方寻访

### 2.1 卖方流程

```
┌─────────────────────────────────────────────────────────────────┐
│                    SELL-SIDE M&A WORKFLOW                       │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  Phase 1: 准备阶段 (Preparation)                               │
│    ├─ 卖方尽调（Vendor DD：法律/财务/税务/商业）              │
│    ├─ 编制 CIM / 管理层演示 材料                               │
│    ├─ 搭建买方长名单                                           │
│    └─ ★ Gate 1: 是否具备出售条件？                            │
│                                                                 │
│  Phase 2: 市场接触 (Market Sounding)                           │
│    ├─ Teaser 分发（匿名/脱敏）→ 签署 NDA                       │
│    ├─ 管理层面谈（一对一）                                     │
│    ├─ 第一轮报价（NBO）收集                                    │
│    └─ ★ Gate 2: 报价是否符合预期？                            │
│                                                                 │
│  Phase 3: 深入阶段 (Deep Dive)                                 │
│    ├─ 选定 2-4 家进入确认性尽调                                │
│    ├─ 数据室开放 + 管理层 Q&A                                  │
│    ├─ 最终报价（FO / BO）收集                                  │
│    └─ ★ Gate 3: 最终报价是否可接受？                          │
│                                                                 │
│  Phase 4: 签约与成交 (Signing & Closing)                       │
│    ├─ 独家谈判 + 签署 SPA                                      │
│    ├─ 审批等待 + 交割条件清除                                  │
│    └─ 交割 + 对价支付                                          │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 2.2 买方寻访路径

| 路径 | 做法 | 适用场景 |
|------|------|---------|
| 行业地图法 | 梳理产业链上下游，识别战略买方和财务买方 | 行业/资源/技术类标的 |
| 同业对标法 | 寻找已做过类似交易的同业 | 有近期可比交易的行业 |
| FA/中介网络 | 通过财务顾问、投行网络触达 | 大型交易首选 |
| 数据库工具 | Wind / Bloomberg / CapitalIQ 筛选 | 财务买方的系统性覆盖 |
| PE/VC 基金 | 梳理关注该赛道的基金（含美元/人民币基金） | 成长型标的 |
| 战略买方 | 梳理国际+BAT+TMT 巨头及二级梯队 | 技术/平台型标的 |
| 政府投资基金 | 国家和地方产业基金、国家队基金 | 关键产业/国资标的 |

### 2.3 买方分级与接触策略

| 级别 | 描述 | 优先级 | 接触策略 |
|------|------|--------|---------|
| Tier A | 战略契合度高 + 出价能力强的买方 | 最高 | 一对一量身定制，积极管理预期 |
| Tier B | 战略契合或出价能力的买方 | 中等 | 统一材料包 + 选择性跟进 |
| Tier C | 观望/兜底型买方 | 低 | 仅提供 Teaser，不主动跟进 |

### 2.4 卖方标的包装要点

- **Teaser（一页纸概要）**：行业定位 + 核心优势 + 财务摘要，匿名分发
- **CIM（Confidential Information Memorandum）**：详细商业计划书，含行业分析、竞争格局、增长策略、历史与预测财务数据
- **管理层路演材料**：展示团队、战略愿景、增长计划
- **VDD（Vendor Due Diligence）报告**：卖方自己做的尽调事先发现问题、修补漏洞，避免在买方尽调中暴露

## 5. 经营者集中反垄断申报（实务）

- **申报标准**：达到《国务院关于经营者集中申报标准的规定》（2024年修订）规定的营业额阈值时，须在交割前事先向市场监管总局申报；未达阈值但具排除竞争效果的，也可能被主动调查。
- **简易程序 vs 普通程序**：符合简易案件标准的（如同一控制下集中、横向重叠小等），可适用简易程序，审查周期较短；否则进入普通程序。
- **未依法申报风险**：应报未报的，可能被责令停止实施集中、限期处分股权/资产、恢复原状，并处以罚款。
- **与时间表衔接**：反垄断申报须作为交割先决条件（CP）纳入时间表，预留审查周期（简易约 1-2 个月、普通更长）。

## 6. 交易核心条款矩阵

并购交易的核心商业/法律条款可归纳为以下要素矩阵，供方案设计与谈判使用：

| 要素 | 常见取值 / 决策点 |
|------|------------------|
| 估值方法与作价 | 收益法/资产法/市场法；是否含控制权溢价 |
| 支付方式 | 现金 / 股份 / 现金+股份组合 |
| 现金 vs 股份比例 | 视卖方流动性需求与买方股权稀释容忍度 |
| 锁定期 | 控股股东 36 月、其他 12 月（A股）；PE 另约 |
| 业绩承诺 | 强制（关联人+收益法）vs 自愿；期限 ≥3 年 |
| 任职与竞业 | 核心人员留任期、竞业范围与期限 |
| 配套融资 | 是否同步募配、用途与上限 |
| 期间损益 | 收益归买方、亏损由转让方补足 |
| 税务处理 | 特殊性税务处理条件（股权支付比例等） |
| 表决权安排 | 表决权委托/放弃、一致行动 |
| 交易保护 | 分手费 / 反向分手费 / MAC |
| 审批先决 | 国资/反垄断/行业准入/ODI |

## 7. 卖方标的包装与 Teaser 脱敏方法论

- **投资故事构建**：提炼 3-5 个 Sales Point，形成"行业逻辑 → 标的优势 → 增长路径"的主线；避免堆砌财务数据，突出差异化。
- **脱敏技巧**：
  - 地域泛化（"华东某省"而非具体城市）；
  - 财务虚数化（采用区间或倍数，避免精确金额）；
  - 主体匿名化（"某细分领域龙头"而非具体商号）；
  - 使用 Project 代号代替真实项目名。
- **Teaser 结构**：封面（Project 代号 + 绝对保密标注）→ 投资亮点 → 业务概览 → 交易意向 → 联系方式（经 NDA 后）。
- 注意：脱敏不等于误导，关键风险须可经尽调验证。

## 8. 投后整合方法论（Day 1 / 百日 / 协同追踪）

- **Day 1 到位事项**：治理席位接管、资金账户管控、核心人员留任确认、IT 与数据访问权限、对外印章证照接管。
- **百日计划**：速赢举措（成本协同、交叉销售）、组织架构调整、制度流程对齐、文化融合启动；以 100 天为节奏设里程碑。
- **协同效应追踪**：将交易假设中的收入/成本协同拆分为可量化指标，建立"假设 → 实现 → 偏差"对照台账，按季度复盘。
- 整合管理宜参考系统化的整合管理体系，将整合作为独立工作流纳入 PMO。

## 9. 跨境支付与 CFIUS

- **跨境换股支付**：以股份作为跨境对价时，须同时满足境内（如 ODI、外资准入）与境外（当地公司法）要求，并办理外汇登记。
- **美国外资投资委员会（CFIUS）审查**：涉及美国业务/技术的交易可能触发 CFIUS 管辖权；交易方可自愿申报或面临强制审查，审查后可附条件批准（缓解措施）或禁止。
- **审批时序协调**：CFIUS、ODI、反垄断（经营者集中）、行业准入等须统一纳入时间表，识别最长路径作为关键路径。
