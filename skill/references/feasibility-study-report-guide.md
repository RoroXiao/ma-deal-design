# 可行性研究报告编写指南

> **适用场景**：大型投资/并购项目可研报告编制——四步法框架、数据收集、财务测算、风险分析、结论形成。**核心受众**：投行分析团队、企业战略投资部、可研报告编制人。**使用方法**：确认投资规模与审批层级 → 按四步法顺序逐章推进 → 交叉核验风险与结论自洽。
> **核心受众**：央企/国企投资部门、上市公司证券部、财务顾问（FA）、工程咨询机构。
> **私企/外企/PE可参考使用**：国家大纲结构具有普适性，可根据具体交易类型和审批要求调整。

---

## 1. 定位：可研报告在M&A全流程中的位置

```
战略规划 ──→ 标的筛选 ──→ 项目建议书 ──→ 预可研 ──→ 正式可研 ──→ 内部决策 ──→ 外部审批 ──→ SPA谈判 ──→ 交割
                                  ↑            ↑           ↑
                              立项备案     初步论证     投资决策依据
```

可研报告不是交易文件，是**投资决策文件**。它综合了尽调、审计、评估、法务、行业研究等多条线的成果，形成一份面向决策层/监管层的结构化论证材料。

### 1.1 预可研 vs 正式可研

| 维度 | 预可研（初步可行性研究） | 正式可研（可行性研究） |
|------|------------------------|----------------------|
| **触发时点** | 项目建议书获批后 | 初步论证通过、尽调基本完成后 |
| **信息来源** | 公开信息 + 管理层路演 + 初步尽调 | 完整尽调报告 + 审计报告 + 资产评估报告 |
| **精度要求** | 投资估算误差 ±20% | 投资估算误差 ±10% |
| **核心问题** | "值不值得做？" | "怎么做？能不能做？" |
| **审批层级** | 企业内部（规划/投资部门） | 董事会/股东会 + 国资委/发改委/外管局/银行 |
| **典型篇幅** | 30-50页 | 100-300页 + 附录 |

> **实际规律**：正式可研通常篇幅为预可研的2-3倍，深度、数据精度、风险分析的完整性明显提升。预可研阶段的主要局限在于尽调尚未完成，大量数据依赖管理层提供而非独立验证。

## 2. 国家大纲标准结构（2023版）

2023年国家发改委发布的《企业投资项目可行性研究报告编写参考大纲》是境内央企/国企编制可研报告的基础性规范。以下为该大纲的核心结构，适用于**各类企业投资项目**。

### 2.1 核心逻辑框架："三大目标、七个维度"

```
三大目标                          七个维度
────────────────────────────────────────────
项目建设必要性  ←──  需求可靠性
项目方案可行性  ←──  要素保障性
                ←──  工程可行性
                ←──  运营有效性
                ←──  财务合理性
                ←──  影响可持续性
项目风险可控性  ←──  风险管控方案
```

### 2.2 标准章节结构

```
一、概述
  1.1 项目概况（全称、地点、规模、工期、投资额、资金来源、模式、技术经济指标）
  1.2 企业概况（基本信息、发展现状、财务状况、类似项目经验、信用和总体能力）
      └─ 国有控股企业须说明上级控股单位主责主业及拟建项目的符合性
  1.3 编制依据（规划、产业政策、行业准入、企业战略、标准规范、专题研究）
  1.4 主要结论和建议

二、项目建设背景、需求分析及产出方案
  2.1 规划政策符合性（与经济社会发展规划、产业政策、行业准入的符合性）
  2.2 企业发展战略需求分析（重大项目：战略对项目需求的紧迫性）
  2.3 项目市场需求分析（业态、目标市场、容量、产业链、价格、竞争力、营销策略）
  2.4 项目建设内容、规模和产出方案（总体+分阶段目标，产品/服务方案及质量要求）
  2.5 项目商业模式（收入来源和结构，商业可行性，模式创新路径）

三、项目选址与要素保障
  3.1 项目选址或选线（多方案比较，土地权属、供地方式、压覆矿产、耕地、生态红线）
  3.2 项目建设条件（自然环境、交通运输、公用工程、施工条件、生活配套）
  3.3 要素保障分析
      └─ 土地要素：规划符合性、建设用地指标、节约集约用地
      └─ 资源环境要素：水资源、能源、碳排放、污染减排

四、项目建设方案
  4.1 技术方案（工艺、流程、配套工程、技术来源、成熟性、知识产权）
  4.2 设备方案（规格、数量、性能、匹配性、关键设备论证）
  4.3 工程方案（标准、总体布置、建(构)筑物、运输、公用工程、安全保障）
  4.4 资源开发方案（资源开发类项目：储量、品质、赋存条件、开发方案）
  4.5 用地用海征收补偿（安置）方案
  4.6 数字化方案（数字化交付，设计-施工-运维全周期数字化）
  4.7 建设管理方案（组织模式、控制性工期、分期实施、招标方案）

五、项目运营方案
  5.1 生产经营方案（产品质量保障、原材料供应、燃料动力、维护维修）
  5.2 安全保障方案（危险因素分析、安全生产责任制、安全管理体系、应急管理预案）
  5.3 运营管理方案（运营机构设置、运营模式和治理结构、绩效考核与奖惩机制）

六、项目投融资与财务方案
  6.1 投资估算（编制范围、编制依据、建设投资+流动资金+建设期融资费用、分年计划）
  6.2 盈利能力分析（收入成本估算、利润表、现金流量表、IRR/NPV、盈亏平衡、敏感性分析）
  6.3 融资方案（资本金和债务资金来源及结构、融资成本、可融资性评价）
  6.4 债务清偿能力分析（DSCR偿债备付率、利息备付率、资产负债率）
  6.5 财务可持续性分析（对企业的整体财务影响：现金流、利润、营收、资产、负债）

七、项目影响效果分析
  7.1 经济影响分析（费用效益分析、对宏观/产业/区域经济的影响）
  7.2 社会影响分析（利益相关者识别、就业带动、社会责任、负面社会影响减缓）
  7.3 生态环境影响分析（污染物排放、地质灾害、水土流失、生态保护、碳减排）
  7.4 资源和能源利用效果分析

八、项目风险管控方案
  8.1 风险识别与评价（全过程风险识别、单一风险p×q评估、整体风险等级）
  8.2 风险管控方案（回避/抑制/转移/承担的应对策略）
  8.3 风险应急预案
  8.4 重大项目社会稳定风险分析

九、研究结论及建议
  9.1 主要研究结论（项目是否可行、是否建议实施的综合判断）
  9.2 相关建议（对决策的具体建议）
  9.3 附表、附图和附件
```

### 2.3 国家对可研报告的"新三性"要求

与2002版旧指南（偏技术论证）相比，2023版强调：

1. **企业投资项目突出经济性** — 聚焦投资收益、市场风险规避
2. **全生命周期视角** — 从"能不能建成"扩展到"能不能运营好、能不能退出"
3. **可持续发展融入** — 绿色发展、自主创新、共同富裕、国家安全、风险管理、数字化

---

### 2.4 融资方案比选（债权 / 股权 / 银团 / ODI / SPV）

可研的融资章节宜对不同融资路径做比选，而非单一假设：
- **债权 vs 股权**：比较资金成本、稀释、偿付压力与期限匹配。
- **银团 vs 双边**：大额跨境并购常需银团贷款，须比较银团牵头行费用、参贷条件与一致性。
- **ODI 资金出境**：境内资金通过 ODI 核准/备案出境的路径、时限与外汇登记要求。
- **SPV 投融资架构**：通过境外 SPV 举债或股权融资的架构选择，及其税务与风险隔离效果。
- 比选须落实到"融资成本区间 + 可得性 + 时间表影响"三维度，支撑交易可行性结论。

## 3. 交易类型 × 可研报告结构映射

尽管国家大纲统一，实践中不同交易类型的可研报告侧重点不同：

### 3.1 跨境股权并购

**典型章节能从国家大纲映射而来，但需追加特定内容：**

| 国家大纲章节 | 跨境并购对应内容 | 权重 |
|------------|----------------|:---:|
| 概述 | 项目概况 + 投资主体 + 编制依据 + 关键结论 | ★★ |
| 建设背景 | → 投资目的地环境分析（国别、产业政策、行业、SWOT） | ★★★ |
| 需求分析 | → 项目必要性分析（国家战略→集团战略→产业链安全→市场） | ★★★ |
| 选址/要素 | → 投资目的地、投资环境 | ★★ |
| 建设方案 | → 业务定位 + 股权投资方案（收购比例、主体、路径） | ★★★ |
| 运营方案 | → 公司治理结构（股东会/董事会/管理层安排） | ★★ |
| 投融资 | 投资估算 + 资金筹措 + 财务评价（模型+指标+敏感性） | ★★★ |
| 影响效果 | 国家/行业/公司三个层面的影响分析 | ★★ |
| 风险管控 | 尽调发现→风险分析→应对策略（可引用风险评估报告） | ★★★ |
| — | **追加：前期工作情况**（尽调、审计、评估、监管体系分析） | ★★ |
| — | **追加：合规性分析**（12维度合规检查） | ★★ |
| — | **追加：退出机制** | ★ |
| — | **追加：实施计划** | ★ |
| — | **附录：尽调发现、估值详情、可比公司、风险矩阵** | ★★ |

**大型跨境并购可研报告的常见规模**：正式可研通常100-300页，其中行业分析（15-30页）、尽调发现（20-40页）、财务评价与估值（20-40页）占主要篇幅。

### 3.2 国内换股吸收合并

**与跨境并购完全不同，核心是交易方案设计而非项目投资建设：**

| 核心章节 | 内容要点 |
|---------|---------|
| 交易目的与意义 | 优化资源配置、培育世界一流上市公司、提升国际竞争力 |
| 交易各方基本情况 | 双方公司概况、股权结构、业务情况、财务数据 |
| 合并方案 | 换股对象、换股价格及比例、异议股东保护（现金选择权） |
| 交易影响分析 | 对上市公司的影响（主营业务、股权结构、财务指标、员工） |
| 风险及对策 | 审批风险、股价波动、内幕信息泄露 |
| 保障措施 | 工作机制、内部沟通、信息披露 |

**关键差异**：不需要"建设方案"和"运营方案"章节，但必须包含换股比例测算、异议股东现金选择权、董事会/股东会程序。

### 3.3 上市公司发行股份购买资产

**介于并购和资产注入之间：**

| 核心章节 | 内容要点 |
|---------|---------|
| 交易各方基本情况 | 上市公司 + 交易对方 + 标的资产 |
| 必要性和可行性 | 战略必要性 + 法规可行性（是否构成重大资产重组、是否触发借壳） |
| 交易方案 | 发行股份购买资产方案、定价基准日、锁定期、业绩承诺（如有） |
| 风险及对策 | 交易方案风险、审批风险、股价波动、估值风险 |
| 保障措施 + 工作安排 + 结论 | — |

> **A股实务**：发行股份购买资产的定价基准日可选董事会决议公告日/股东大会决议公告日/发行期首日，价格不低于基准日前20/60/120个交易日均价的80%（2023年全面注册制后规则）。

### 3.4 央企间重组/无偿划转

**结构特点**：重心在行业背景分析和战略逻辑，交易条款相对简单（无偿划转或行政划转）：

| 核心章节 | 内容要点 |
|---------|---------|
| 重组背景 | 行业发展问题（集中度低、技术创新不足、环保欠账、贸易环境） |
| 行业转型要求 | 并购重组→打造全球竞争力 + 技术创新 + 绿色制造 + 高效运营 |
| 双方优势与挑战 | 各自经营能力、产品结构、区位优势、短板 |
| 重组必要性和意义 | 提升集中度→去产能→提质增效→国际竞争力 |
| 重组方案与可行性 | 具体操作路径 |
| 预期效果 | 规模指标、财务指标、协同效应 |
| 风险提示与对策 | 整合风险为主 |

### 3.5 跨境资源类并购

**与一般跨境并购类似但更侧重资源储量验证：**

| 核心特点 | 说明 |
|---------|------|
| 行业分析深度 | 每种标的金属/矿产品逐品种分析全球供需、价格、库存、成本曲线 |
| 资产核实 | 逐矿权验证储量/资源量/品位、采选成本、服务年限 |
| 多法域协调 | 上市公司注册地 + 运营所在国 + 勘探所在国，多套法规体系叠加 |
| 估值 | DCF核心假设（金属价格、产量曲线、资本开支），可比公司+先例交易交叉验证 |
| 投后管理挑战 | 境外上市实体 + 境内国资股东的治理平衡 |
| 竞价风险 | 公开竞购流程下的不确定性 |

---

### 3.6 退出机制细化（四要素）

跨境股权并购可研的"退出机制"宜细化为四要素，避免仅泛泛而谈：
- **一般退出**：IPO、转售给战略/财务投资人、二级市场交易的可行路径与预计窗口。
- **随售权（Tag-along）**：小股东随控股股东退出时的权利安排与定价机制。
- **退出合作**：与合资/合作方的退出协调机制（如优先购买、拖带衔接）。
- **同业竞争**：退出后是否保留业务重叠、竞业限制与豁免安排。
四要素须与交易结构（持股比例、治理席位）联动设计。

### 3.7 跨境税务治理条款与 deal breaker

跨境可研须预判税务治理与交易保护条款：
- **CFC / FSIE**：受控外国企业规则与离岸被动收入豁免（如香港 FSIE 制度）对持股架构与利润分配的影响。
- **税收协定**：利用双边税收协定降低预提税，须满足受益所有人等反滥用测试。
- **随售权 / 同业竞争 / 董事会席位**：这些治理条款直接影响退出与协同，须在可研中预设。
- **Red flag 与 deal breaker**：明确哪些税务/合规事项构成交易否决项（如无法穿透的最终受益人、未决重大税务争议），并在可研中单列风险红线。

## 4. 可研报告的关键量化指标体系

央企/国企可研报告必须包含以下定量指标（用于国资委备案和银行审贷）：

| 指标类别 | 关键指标 | 常用基准 |
|---------|---------|:---:|
| **盈利能力** | 项目IRR（全投资内部收益率） | ≥行业基准收益率（钢铁8-10%、矿产10-12%） |
| | 资本金IRR | ≥融资成本+风险溢价 |
| | NPV（净现值） | >0 |
| | 投资回收期（静态/动态） | ≤行业平均水平 |
| **偿债能力** | DSCR（偿债备付率） | ≥1.3（银行最低要求≥1.1） |
| | 利息备付率 | ≥2.0 |
| | 资产负债率 | 不超过国资委预警线 |
| **敏感性** | 关键变量±10%对IRR的影响 | IRR下降不超过基准线 |
| | 盈亏平衡点（BEP） | 产能利用率≤70-80% |
| **规模指标** | 投资总额（含铺底流动资金） | — |
| | 资本金比例 | ≥国家最低要求（一般20-30%） |
| | 年均营业收入/净利润 | — |

### DCF估值核心假设（并购类可研必含）

```
┌─ 收入端假设 ─────────────────────────────────
│  销量曲线（产能爬坡节奏）
│  价格基准（参考历史均值/独立机构预测/长期边际成本）
│  产品结构（不同品种的价差和毛利率差）
│
├─ 成本端假设 ─────────────────────────────────
│  原材料单耗和单价（矿石品位、还原剂、合金、电力）
│  人工成本（当地工资水平+外派人员成本+年涨幅）
│  折旧摊销（资产基础+残值率+年限）
│  运输和销售费用
│
├─ 融资假设 ───────────────────────────────────
│  资本金比例、并购贷款利率、还款计划
│  汇率假设（当地币→美元→人民币的折算链条）
│  预提税/股息税
│
└─ 终值假设 ───────────────────────────────────
   永续增长率、退出倍数、终值占比（不宜超60-70%）
```

## 5. 可研报告的合规性检查清单（央企/国企专用）

依据国资委《中央企业境外投资监督管理办法》等监管要求及央企实务规范，可研报告至少需覆盖以下12项合规性检查：

| # | 合规维度 | 检查要点 |
|:--:|---------|---------|
| 1 | 法规政策合规性 | 是否违反产业政策、负面清单、国别制裁 |
| 2 | 规划合规性 | 与集团战略规划和主责主业是否一致 |
| 3 | 决策流程合规性 | 是否履行了项目建议书→预可研→正式可研的内控流程 |
| 4 | 外部审批合规性 | 发改委核准/备案、商务部备案、外管局登记、反垄断审查 |
| 5 | 经济指标合规性 | IRR是否达基准、资本金比例是否合规 |
| 6 | 法人治理合规性 | 投资主体是否具有独立法人资格和投资能力 |
| 7 | 安全环保合规性 | 标的EHS合规、碳排放指标 |
| 8 | 财会税务合规性 | 审计意见类型、转让定价、跨境税务成本 |
| 9 | 投资能力合规性 | 项目总投资是否在集团授权范围内、杠杆率是否超标 |
| 10 | 经营风险合规性 | 尽调发现的重大风险是否已制定应对方案 |
| 11 | 海外用工合规性 | 外派人员比例、当地化用工要求、工会 |
| 12 | 党建要求 | 境外项目党组织的设置方式（央企特色要求） |

## 6. 专家评审会流程

重大项目的可研报告须经过专家评审会审议。以下为基于央企实务总结的标准流程：

### 6.1 评审会基本要素

| 要素 | 说明 |
|------|------|
| **触发时点** | 可研报告初稿完成、内部修改意见处理完毕后 |
| **参会方** | 集团相关部门 + 项目工作组 + 可研编制单位（投行/FA）+ 其他中介机构 |
| **专家来源** | 内部专家（企业内部各专业人员）+ 外部专家（独立第三方） |
| **专家分组** | 通常分为综合商务组 / 生产工艺组（或技术组） / 公辅组 |
| **保密要求** | 签署保密承诺书、资料加密传输 |

### 6.2 评审专业维度清单

**综合商务组** — 法律、投资环境及产业政策、行业市场、规划、财务、税务、资金、风险管理、交易架构及投资路径、公司治理、人力资源

**生产工艺/技术组** — 工艺、设备、产品规格及产量、电气、技术经济

**公辅组** — 电力、给排水、总图、交通运输、能源环保、安全

### 6.3 评审会标准流程

```
Day -2:  发送会议通知 → 专家反馈保密承诺书 → 发放项目资料（加密）
Day -1:  专家自行审阅项目资料
Day 0:
  上午  签到、提交保密承诺书原件
        FA进行可研汇报（全员，约30-45分钟）
        专业组分组讨论（各组指定组长，逐位发言，记录员现场记录）
        形成分组意见，专家签字
  下午  组长会议 → 汇总形成总体意见 → 签字
```

### 6.4 内部修改意见的典型模式

企业在提交正式可研报告前通常会经过多轮内部修改。修改意见通常聚焦：

- **措辞精准度**：愿景→目标→规划的统一表述，避免不一致的表述出现在不同章节
- **数据一致性**：不同章节引用的同一数据（如产能目标、收入预测）不得冲突
- **战略层级对齐**：从集团总体战略 → 板块战略 → 本项目必要性的层层逻辑，不能跳层
- **敏感数据的审慎处理**：产能目标、资源自给率、估值数据等需与公开披露口径协调
- **避免多章节重复叙述**：同一论点不宜在多处反复展开，应采用"详见第X章"的交叉引用方式

---

### 6.5 专家评审粒度（工程条线 × 专业矩阵）

大型/资源类可研的专家组评审，宜按"工程条线 × 专业"细分，避免笼统：
- **工程条线**：如冶炼、码头、电厂、LNG、水库、公辅等，每条线独立评审技术与工期。
- **专业维度**：按约 13 类专业（工艺、设备、电气、土建、安全、环保、经济等）配置专家。
- **矩阵呈现**：以"条线 × 专业"矩阵列出每项评审要点、负责专家与结论，确保全覆盖、可追溯。
- 该粒度用于央企/资源类项目的专家评审会，是可研通过质控的关键。

### 7.1 按交易类型选择

| 你的交易类型 | 参考章节结构 |

### 7.2 按可用资源选择

| 你现在有什么 | 建议编制 |
|------------|---------|
| 只有项目建议书 + 公开信息 | 编制预可研（30-50页） |
| 完成尽调 + 审计 + 评估 | 编制正式可研（100-300页） |
| 尽调进行中 + 初步结论 | 编制预可研，标注"待尽调验证" |

### 7.3 通用启动骨架

如果你不确定从哪开始，以下骨架适用于大多数并购类可研项目：

```
1. 概述（3-5页）
   - 项目概况 | 投资主体 | 编制依据 | 主要结论

2. 投资环境与必要性分析（10-15页）
   - 宏观环境 | 行业分析 | 标的SWOT | 战略必要性

3. 前期工作情况（5-10页）
   - 尽调主要发现 | 审计/评估结论 | 风险评估

4. 投资方案（10-15页）
   - 业务定位 | 股权收购方案 | 交易架构 | 公司治理

5. 投资估算与融资（5-10页）
   - 投资估算 | 融资方案 | 资金筹措计划

6. 财务评价（10-20页）
   - 估值模型 | 盈利预测 | 核心指标(IRR/NPV/回收期) | 敏感性分析

7. 风险分析与缓释（5-10页）
   - 重大风险项 | 应对策略 | 风险→条款映射

8. 合规性分析（3-5页）
   - 12项合规检查点逐一确认

9. 实施计划与退出机制（3-5页）
   - 时间表 | 关键节点 | 退出路径

10. 结论与建议（1-2页）
    - 综合评价 | 建议董事会审批

附录（不限篇幅）
    尽调发现详情 | 可比公司分析 | 估值详情 | 法律意见摘要
```
