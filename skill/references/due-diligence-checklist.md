# 尽职调查

> **适用场景**：并购交易五线尽调（法律/财务/税务/商业/技术）——从首轮资料收集到最终报告的全流程检查与工具。**核心受众**：尽调项目经理、投行/律所/会计师执行层。**使用方法**：先确定尽调范围（全部/仅法律/仅财务等），再按 Phase 1-5 节奏操作；每个 Phase 有明确 checklist。

---

## 1. 尽调方法论

### 1.1 基本原则

- **独立验证**：不依赖管理层口头陈述，须交叉验证文档、数据、第三方信息
- **风险导向**：先识别高风险领域，分配最多资源；低风险领域可适当简化
- **穿透到底**：对于依赖关联方/核心客户/关键供应商的业务，须穿透至最终交易实质
- **动态追踪**：首轮清单 → 补充清单 → 管理层访谈 → 现场考察 → 问题整改跟踪，层层递进
- **反向影响交易**：尽调发现不应只是报告中的陈述，而应反向影响交易结构（对价调整、条件先决、赔偿条款、过渡期安排）

### 1.2 尽调工作节奏

```
Phase 1: 首轮资料收集（5-10 business days）
  ├── 发出首轮尽调清单（分财务、评估、税务、法律、业务五线）
  ├── VDD 数据室搭建 → 逐份资料下载审阅
  ├── 同步发出管理层访谈清单（至少提前3个工作日）
  └── 标红/标黄/标绿优先级，分批催收

Phase 2: 管理层访谈 + 补充清单（5-7 days）
  ├── 管理层全景访谈（CEO/CFO/业务总监/法务总监等）
  ├── 职能部门访谈（采购/生产/销售/研发/质控/人力/安环）
  ├── 根据首轮文件和访谈发现，发出补充/验证性资料请求
  └── 第三方法律函证、银行函证、客户/供应商确认

Phase 3: 现场考察（2-3 days）
  ├── 走访主要生产基地/运营场所
  ├── 实地验证：设备运行状态、库存实物、安全措施、产能真实性
  └── 与管理层和一线员工非正式交流，获取"不在文件中"的信息

Phase 4: 问题发现 → 风险分级 → 交付报告（5-7 days）
  ├── 汇总所有发现，按风险等级分类
  ├── 每股发现附：事实 → 风险判定 → 对交易影响 → 建议 → 管理层回应
  ├── 撰写尽调报告，内部交叉复核
  └── 与客户沟通关键发现，确认交易结构调整建议

Phase 5: 问题整改跟踪（Post-report）
  ├── 对交割先决条件中的事项，跟踪整改完成情况
  └── 确认赔偿条款覆盖的或有事项最新状态
```

## 2. 尽调清单分级体系

### 2.1 清单设计原则

一份好的尽调清单需要做到：
- **分类清晰**：按财务/评估/税务/法律/业务等维度独立成列
- **优先级标注**：标红（must-have, 优先级最高）→ 标黄（重要但次之）→ 标绿（nice-to-have）
- **逐笔催收**：每项标注"已交/未交/不适用"并留备注栏，持续追踪完成率
- **分阶段递进**：一轮清单是"大盘资料"，二轮清单是"针对发现的深入拆解"
- **结论导向**：清单不是为了"全部交齐"，而是为了"对交易决策形成足够判断"

### 2.2 资料催收与管理

| 催收里程碑 | 内容 | 典型截止日 |
|-----------|------|-----------|
| T + 5 business days | 标红资料（公司基本情况、近三年审计报告/财务报表、营业执照、公司章程、股权结构图） | Priority 1 |
| T + 10 business days | 标黄资料（重大合同、近三年纳税申报表、员工花名册、关联交易明细） | Priority 2 |
| T + 15 business days | 标绿资料（其他补充性资料） | Priority 3 |

> 对于跨境标的，因时区/语言/配合意愿的差异，资料催收周期通常需延长50%以上。

### 2.3 清单与报告的闭环

每一条清单资料都应服务于报告中的具体结论，避免"为收而收"：

| 清单条目 | 报告中的对应章节 | 不提供的后果 |
|---------|----------------|------------|
| 近三年审计报告 | 盈利质量分析、正常化调整 | 无法出具财务DD结论 |
| 重大客户合同 | 收入可持续性、客户集中度 | 评估客户流失风险缺依据 |
| 纳税申报表 + 税收优惠文件 | 税务合规、优惠到期影响 | 税务风险敞口无法量化 |
| 土地使用权证/不动产权证 | 资产权属、抵押核实 | 资产瑕疵导致交易对价不确定性 |
| 银行对账单 + 余额调节表 | 现金真实性、资金归集 | 无法核实报表数字真实性 |

## 3. 财务尽调核心关注点

### 3.1 盈利质量（Quality of Earnings）

> 核心问题：报表利润在多大程度上反映了标的真实、可持续的盈利能力？

**正常化调整（Normalization Adjustments）典型来源：**

| 调整类型 | 示例 | 调整方向 |
|---------|------|---------|
| 非经常性收益 | 资产处置收益、政府一次性补贴、保险理赔 | 调减 |
| 非经常性损失 | 一次性重组费用、自然灾害损失 | 调增 |
| 关联交易定价偏离 | 关联方以低于市场价提供原材料 | 调减（还原至市场价） |
| 股东个人支出 | 股东个人车辆/差旅/会所费用由公司承担 | 调增（加回） |
| 非核心业务损益 | 持有的投资性房地产公允价值变动 | 单独列示 |
| 停止经营业务 | 已关闭/待出售业务的损益 | 单独列示 |

**收入确认实质性审查：**
- 是否有提前确认收入（channel stuffing, bill-and-hold）？
- 合同负债（预收账款）是否合理，是否隐藏递延收入风险？
- 完工百分比法（POC）的关键假设是否合理？
- 退货率、质保金等可变对价的估计是否充分？

### 3.2 营运资金（Net Working Capital）

> 核心问题：维持业务正常运转需要多少"常态"资金？

**分析方法：**
1. 获取最近3年 + 本年的月度 NWC 数据
2. 剔除异常月份（如年末集中回款/付款）
3. 计算月均 NWC，作为"常态营运资金"锚定值
4. 分析趋势：NWC 在上升（业务扩张？回款恶化？）还是稳定？

**关键指标：**
- DSO（Days Sales Outstanding）= 应收账款 / 日均收入
- DIO（Days Inventory Outstanding）= 存货 / 日均成本
- DPO（Days Payable Outstanding）= 应付账款 / 日均成本
- Cash Conversion Cycle = DSO + DIO - DPO

### 3.3 关联交易穿透

> 核心问题：剥离后，这些交易能否以相近条件在市场化环境中维系？

- 关联采购占比？定价基准（市场价/成本加成/协商价）？
- 关联销售占比？是否存在通过关联方转移利润（向低税率地集中利润）？
- 共享服务（IT、人力、采购、财务）的成本分摊机制是否合理？
- 资金归集（Cash Pooling）安排：每日归集/定期归集？交割后能否独立运行？过渡期需要多长？

### 3.4 债务与表外风险

> 核心问题：交割后实际承债有多少？哪些会被交易触发？

- 交叉违约条款：控制权变更是否导致提前还款义务？
- 表外负债：对外担保、未决诉讼的合理估计、环境修复义务、股权激励回购义务
- 资金池归集后的净债务计算：法人口径 vs. 合并口径
- 限制性条款（negative pledge, financial covenants）的合规状态

## 4. 法律尽调核心关注点

### 4.1 资产权属真实性

| 资产类别 | 审查文件 | 常见瑕疵 |
|---------|---------|---------|
| 土地使用权 | 土地证、出让合同、出让金发票 | 集体土地未转征、划拨地擅自转让、出让金欠缴 |
| 房屋建筑物 | 不动产权证、建设工程规划许可证 | 无证建筑、未验收即投入使用、面积超规 |
| 矿业权 | 采矿许可证、资源储量报告、开发利用方案 | 矿权到期未续、开采范围超界、储量报告过期 |
| 知识产权 | 专利/商标注册证、许可协议 | 职务发明归属不清、核心专利即将到期、商标被异议 |
| 车辆/船舶/飞机 | 登记证书 | 挂靠第三方名下、抵押未注销 |

### 4.2 诉讼与或有负债的风险分级

```
高风险 → 影响交易可行性的因素
  ├── 标的公司作为被告的未决诉讼，索赔金额重大（>EBITDA 20%）
  ├── 核心资产（土地、厂房、矿权）存在权属争议
  ├── 核心知识产权被诉侵权，可能导致业务停滞
  └── 刑事调查或重大行政处罚（吊销许可证风险）

中风险 → 影响交易对价但不影响可行性
  ├── 劳动争议（社保欠缴、工伤索赔）
  ├── 普通合同纠纷
  ├── 税务稽查（无刑事性质）
  └── 环境处罚（可整改）

低风险 → 正常经营中的零星纠纷
  ├── 供应商/客户普通货款纠纷
  ├── 员工离职竞业限制纠纷
  └── 小额行政处罚
```

### 4.3 合规体检（Clean Bill of Health Check）

交叉核查以下五个维度是否有合规缺口：
- **行业许可**：是否持有业务经营所需的所有许可证照？有效期是否覆盖交易时间线？
- **环境合规**：环评批复、排污许可证、危废处置资质是否齐全？是否有未整改的环保督查问题？
- **劳动合规**：社保公积金是否足额缴纳？劳务派遣比例是否超标（10%法定上限）？
- **外汇合规**：跨境资金流动是否完成外汇登记/备案？返程投资是否合规？
- **数据/网络安全**：是否涉及个人信息出境？是否在关键信息基础设施行业清单内？

## 5. 尽调发现 → 交易结构映射

| 尽调发现 | 风险等级 | 交易结构调整 | 典型条款 |
|---------|---------|------------|---------|
| 盈利质量存疑（大量非经常性损益） | 高 | 降低现金对价 + earn-out | Earn-out 期2-3年，与未来EBITDA/收入挂钩 |
| 未决重大诉讼 | 高 | 卖方全额赔偿 + escrow | Escrow 冻结对价的15-20%，期限覆盖诉讼 |
| 税务稽查/历史欠税 | 高 | 税务赔偿条款 + 更长的索赔期限 | Tax indemnity，索赔期6-7年 |
| 核心资产权属瑕疵 | 高 | 交割先决条件 | 必须在交割前完成确权/补证 |
| 关联交易依赖度高 | 中 | 过渡期服务协议（TSA） | TSA 6-12个月，明确关键服务的定价和终止 |
| 客户集中度高 | 中 | 对价与客户留存挂钩 | 若Top 3客户交割后12个月内流失，按比例下调对价 |
| 关键人风险 | 中 | 锁定期 + 竞业禁止 | Lock-up 2-3年，Non-compete 2年覆盖核心市场 |
| 环境修复义务 | 中 | 环境赔偿 + 金额托管 | Special indemnity, escrow覆盖预估修复费120% |
| 社保欠缴 | 低 | 交割后由买方补缴或price adjustment | 在 Completion Accounts 中作为负债扣除 |

## 6. 尽调报告标准交付结构

### 6.1 报告目录（整合 FDD + TDD + LDD）

```
1. 释义（Definitions）
   - 关键术语定义：交易标的、审阅期间、基准日、各方简称
   - 避免正文中反复解释

2. 摘要与重要风险提示（Executive Summary）
   - 工作范围和方法
   - 盈利质量快照（报告 vs. 调整后 EBITDA）
   - 净债务与常态营运资金
   - 关键交易关注事项表（Issue / Risk Level / Impact / Recommendation）

3. 交易概况
   - 交易背景、目标公司架构图、关键假设

4. 财务尽调
   - 重要会计政策摘要及DD判断
   - 收入分析（按产品/地域/客户拆分、集中度、确认质量）
   - 毛利分析（按产品线、驱动因素）
   - 营业费用分析（非经常性/异常项目）
   - 正常化调整明细（逐笔说明性质、金额、调整理由）
   - 资产负债表分析（AR/存货/固资/在建工程/无形资产/债务）
   - 关联交易深度分析
   - 现金流（经营性/投资性/筹资性，自由现金流）
   - 或有负债与表外项目
   - 各实体尽调发现（逐家）
   - 管理层陈述清单

5. 税务尽调
   - 税务概况（各实体、各税种、适用税率）
   - 纳税申报及合规情况
   - 税收优惠清单（法律依据、到期日、续期风险评估）
   - 转让定价（交易量、文档完整度、风险评估）
   - 税务稽查及争议历史
   - 递延所得税分析
   - 可结转税务亏损
   - 交易相关税务专项（资产/股权收购选择、跨境预提税、计税基础）

6. 法律尽调
   - 公司事项（设立存续、股权结构、历史变更）
   - 许可证照
   - 不动产及资产权属
   - 知识产权
   - 重大合同
   - 诉讼与争议（含风险分级）
   - 劳动人事
   - 环境
   - 监管（反垄断、外资准入、行业监管、数据安全、制裁）

7. 其他重要风险
   - 政策风险、市场/价格风险、战略风险、整合风险、融资风险

8. 附录
   - 资料清单索引
   - 访谈纪要索引
   - 关键财务附表（调整后利润表/资产负债表/净债务计算/营运资金计算）
   - 重大合同摘要
   - 许可证照登记表
```

## 7. 跨境尽调特别提示

### 7.1 多法域协调

- 母公司所在国 + 各运营子公司所在国，可能需要分别委托本地律师
- 注意不同法域的文件格式、语言、会计准则差异
- 外汇管制国家（如印尼、印度、部分非洲国家），资金跨境流动需额外审批

### 7.2 境外标的的银行函证

- 部分国家的银行不提供标准银行函证服务
- 替代方案：获取银行对账单 + 余额调节表 + 管理层确认
- 注意当地是否存在资金管制（如强制结汇、利润汇出限制）

### 7.3 反腐败与制裁筛查

- 标的公司及关联方是否在任何制裁名单上（SDN, EU, UK, UN）？
- 业务是否涉及受制裁国家/地区/行业？
- 历史交易是否涉及高风险中间商或政府官员？是否需要反腐败专项尽调？

## 9. ESG 尽职调查（DDQ）

ESG 尽调宜作为独立模块（DDQ），覆盖：
- **EHS（环境、健康、安全）**：排污许可、环评批复、安全事故记录、职业健康合规。
- **社会责任**：用工合规（童工/强迫劳动/工会）、供应链劳工标准、社区关系与土著权益。
- **闭坑与复垦**：矿业等项目的闭坑义务、复垦基金计提与历史欠账。
- **社区与土地**：征地拆迁合法性、社区补偿与抗议风险。
DDQ 须形成专项问卷与发现清单，重大 ESG 缺陷应作为 red flag 上报。

## 10. 数据请求管理（Data Request）

尽调数据催收宜工程化，采用标准化 Data Request 模板：
- **字段结构**：模块（财务/法律/税务/HR/IT…）× 子项 × 资料要求 × 截止日 × 状态（未提供/部分/已提供）× 备注。
- **状态三态追踪**：以颜色或标签标记每份资料的催收状态，定期刷新。
- **责任到人对接**：每个模块指定卖方对接人与买方尽调负责人，避免遗漏。
该模板可沉淀为 Excel/在线表单，与 VDR 权限联动。

## 11. 访谈提纲与现场问卷

- **管理层访谈提纲**：按职能（财务/法务/业务/HR/技术）列问题清单，标注"主要问题"并设计交叉验证点。
- **现场问卷**：赴标的企业现场按主题设问，覆盖资产状况、产能、合规与员工访谈，形成现场记录模板。
- 访谈与问卷发现须与书面资料交叉验证，差异点列入 red flag。
- 具体模板见 `assets/02-due-diligence-interview-template.md`（访谈模板）。

## 12. 尽调问题清单范式（问题跟踪表）

以下为真实项目第一阶段尽调问题脱敏后的通用范式，可作为买方尽调"问题跟踪表"模板。每项须明确**责任方、建议解决时间节点、对交易的影响**，并持续滚动更新至交割。

| 序号 | 问题类别 | 具体事项（脱敏范式） | 建议解决时间节点 | 交易影响 |
|-----|---------|-------------------|---------------|---------|
| 1 | 投资备案 | 扩产项目总投资额备案信息与实际出入，连带用地、建设内容、效益测算偏差；需重新办理环评/能评变更 | 申报前 | 影响估值基础与合规 |
| 2 | 能耗合规 | 获批能耗总量/单耗低于实际耗用，面临处罚乃至停工整改 | 申报前 | 持续经营重大风险 |
| 3 | 财务核算 | 未按工序核算成本、材料领用跨期、分摊依据不当、未核算在产品，毛利率失真 | 年报出具前 | 盈利质量（QoE）存疑 |
| 4 | 明股实债 | 子公司存在明股实债，国资主体退出须履行审批/进场程序，拖慢交易进度 | 申报前 | 影响交易确定性与时间表 |
| 5 | 对赌回购 | 标的与基金签署对赌回购条款，股/债定性不明，影响 100% 并表及评估值 | 申报前 | 直接影响评估值与并表 |
| 6 | 资产权属 | 车间加盖厂房无建设规划许可、权属争议、使用权瑕疵 | 交割前 | 资产完整性风险 |
| 7 | 租赁合规 | 租用大股东土地/厂房，历史年度未计提租金 | 年报出具前 | 损益完整性 |
| 8 | 社保公积金 | 未为全部员工缴纳住房公积金、未为部分员工缴纳社保 | 申报前 | 合规与潜在补缴 |
| 9 | 出资合规 | 债权转股权出资未提供评估报告 | 交割前 | 出资瑕疵 |
| 10 | 土地合规 | 承租集体土地并建设厂房 | 交割前 | 权属与合规风险 |

> 使用提示：该范式源自真实项目，已脱敏为通用结构。实际项目应结合行业特性（如重资产、化工、出口等）与标的具体情况补充，并逐项落实责任人与关闭节点。

## 13. 困境资产 carve-out 法律尽调要点（剥离型交易）

当标的资产从原主体**剥离**至新设主体（如为 re-IPO 或独立引资而做的资产归集）时，除通用尽调外，须重点核查"划转障碍"——即资产/业务/人员能否干净地转移到新主体。以下为脱敏后的五类典型障碍与股权权利负担核查。

### 13.1 资产划转五类障碍

| 序号 | 障碍类别 | 具体表现（脱敏范式） | 交易影响 |
|-----|---------|-------------------|---------|
| 1 | 不动产权利受限 | 部分拟划转不动产存在抵押、查封或权利受限，无法直接过户 | 须先解押/解除限制，否则划转受阻 |
| 2 | 利用与改造要求 | 部分不动产附带利用、改造或产能维持要求，划转后须继续履行 | 增加承接主体义务与成本 |
| 3 | 知识产权划转 | 知识产权划转须有定价与转移安排（评估、转让登记） | 无妥善安排则权属不清、估值失真 |
| 4 | 行政许可承继 | 部分生产经营必需的行政许可证书**不能直接承继**至新主体，须重新申请 | 划转后存在"无证经营"空窗期，须提前规划续证 |
| 5 | 人员转入 | 相关人员转入新主体时的劳动合同变更、保密与竞业禁止协议、股权激励衔接 | 处理不当引发劳动争议与核心人流失 |

### 13.2 股权质押冻结的实质障碍

- 若原主体所持标的股权**被全部质押/司法轮候冻结**，则该股权转让在解除权利负担前**无法交割**；
- 尽调须核查：质押权人（如债券受托管理人）、冻结法院与案由、冻结期限与状态、是否影响本次交易范围；
- 该事项应作为**交割先决条件**在交易文件中明确，并在立项/合规问答中向内控说明"方案已考虑该因素影响，不构成实质障碍"。

### 13.3 carve-out 尽调交付建议

- 五类障碍 + 股权权利负担应纳入**尽调问题跟踪表**（见 §12），逐项落实责任人与关闭节点；
- 行政许可不能承继的，须在前端设计"过渡期经营安排"（如原主体代持/授权使用至新证取得）；
- 人员转入涉及股权激励的，须与 §5.4 经营团队持股安排（见 `distressed-ma-guide.md`）统筹设计，避免激励断层。

## 14. 境内资源类 / 矿业权资产尽职调查（专项）

> 适用场景：收购境内矿业企业（稀土、金属、非金属矿等）控股权或重要 minority 股权时，矿产资源本身是核心价值载体，须在传统财务/法律/业务尽调之外补充**矿业权专项**。本章与 `mining-investment-guide.md`（偏跨境 JORC/ODI）互补——本章聚焦**境内矿权的合规性与可持续性**。

### 14.1 尽调定位与红线

- 矿业企业的核心资产是**矿业权 + 资源量/储量**，而非账面净资产；
- 在行业配额/指标管理制度下，须关注采矿权证合规性、生产规模是否与配额匹配、是否存在影响持续稳定生产的因素；
- 矿权瑕疵（生态红线、越界开采、未批先建、质押查封）可能直接构成**交割先决条件**甚至交易终止项。

### 14.2 矿业权核心核查清单

| 核查维度 | 关键问题 | 取证要点 |
|---|---|---|
| 权证有效性 | 采矿证/探矿证是否在有效期内、面积/矿区范围/生产规模/开采方式 | 权证原件、发证机关层级 |
| 取得方式与开发条件 | 原始取得 or 受让取得；是否已实际开采/具备开发条件 | 初设/可研/核准批复、整合批复 |
| 历史权属与账面价值 | 取得时间、审批层级、近两年权属变更、期末账面价值、对经营的重要程度 | 权属变更文件、账务凭证 |
| 储量核实与评审备案 | 最近一期矿产资源储量核实报告、专家评审意见、储量评审备案文件 | 核实报告+备案文件 |
| 矿权争议/重叠 | 是否与他方矿权重叠、交叉或存在现实/潜在矿界争议 | 矿区范围图、争议说明 |
| 生态红线与基本农田 | 矿区范围是否涉及生态红线、是否占用基本农田 | 自然资源部门核查文件 |
| 合作开采/承包 | 是否存在合作开采、矿产承包，是否依法审查备案 | 合作协议/承包协议及备案 |
| 矿业权整合 | 是否存在整合情形及整合文件 | 整合批复 |
| 费用缴纳 | 矿业权使用费、资源税、权益金等缴纳情况及凭证 | 缴纳凭证 |
| 复垦与治理 | 矿山复垦及治理费用计提/实际支出 | 复垦方案、费用台账 |
| 非法开采风险 | 是否存在破坏性/越界/超规模/无证开采 | 监管检查记录、处罚情况 |
| 权利限制 | 矿业权是否存在质押、查封、诉讼仲裁争议 | 质押合同、司法文书 |
| 人员配备 | 矿业管理人员、地质专业人员是否齐备，经验是否匹配 | 人员名册、资质 |
| 无证实际开采 | 是否存在实际探采但未取得矿业权的情形 | 自查说明及佐证 |

### 14.3 土地与房产权属（生产型企业必查）

- 自有土地性质：国有出让 / 有偿处置（作价出资或授权经营）/ 国有划拨（是否符合划拨目录并取得县级批准）/ 集体经营性建设用地（是否符合流转政策）；
- 自有房产：是否已取得房产证；
- 租赁土地/房产：清单与权属文件、是否办理租赁备案；
- 在建工程：立项批复、用地/工程/施工/消防许可、环评批复；拟建项目固定资产备案与核准；
- 林地/永久设施：排土场等生产设施若占用林地，须核查林地审批与永久建设用地审批。

### 14.4 环保与安全合规

- 污染物排放（废水/废气）是否符合环保法规，是否履行环评手续、取得排污许可；
- 含硫/伴生有害元素较高的矿种，须重点检索**公开负面报道/环保处罚记录**，评估环境负债与持续经营风险；
- 安全生产"三同时"要求、安全生产许可证；
- 环保投入、设施与费用是否匹配产能。

### 14.5 瑕疵规范路径与交割安排

- 矿权/土地/环保瑕疵，建议在签约前推动规范整改，并将未决事项列为**交割先决条件（CP）**；
- 存在采矿权抵押借款等资产受限的，须提前与债权人沟通并取得同意，准备应对方案；
- 参股公司若为民营企业且利润贡献高，须核查其超额生产、重大环保等合规风险，判断投资收益可持续性；必要时考虑剥离参股权方案。
