# NDA审查清单

> **适用场景**：并购交易中的保密协议（NDA / CA / Confidentiality Agreement）审查——站在项目组角度逐条核对。**核心受众**：交易团队、投行执行层、企业法务。**使用方法**：买方/卖方角色确认后，按清单逐项审查；买卖方分歧处标注优先采纳谁的标准。

---

## 1. 买卖方立场差异矩阵

NDA 的每一条款在买卖双方眼里关注点完全不同。签署前先确认己方角色：

| 条款 | 买方关注（信息接收方） | 卖方关注（信息披露方） |
|------|---------------------|---------------------|
| 保密信息范围 | 尽可能窄+有明确排除项 | 尽可能宽（含口头信息、含交易事实本身） |
| 使用限制 | 评估潜在交易即可，允许内部分析 | 严格限制——包括限制分析人员的范围 |
| 接收方范围 | 员工+外部顾问+融资方，定义宽泛 | 限定名称列举（named persons only） |
| 保密期限 | 18-24个月足够 | 3-5年 + 商业秘密永久 |
| 返还/销毁 | 30-60天内+允许保留电子副本 | 立即+确认销毁清单+不保留任何副本 |
| 竞业限制 | 无或极窄（不因 NDA 影响主业） | 明确禁止利用保密信息与标的竞争 |
| Standstill | 不接受或严格的时限/条件 | 禁止在特定期限内收购或接触标的管理层 |
| 非招揽/非挖角 | 仅限与交易相关人员 | 扩展到全公司所有员工 |
| 禁令救济 | 可以接受（NDA 通常的救济手段） | 更重视损害赔偿+禁令救济 |
| 管辖法 | 己方法域 | 己方法域 |
| 争议解决 | 己方所在地法院 | 仲裁（保密性好） |

## 2. 保密协议审查清单

### 2.1 保密信息范围

- [ ] **定义清晰**：明确列出哪些信息属于保密信息
- [ ] **排除项完整**：
  - 签署前因非交易事由已获知的信息
  - 从第三方获知且不受保密义务约束的信息
  - 非使用保密信息而自行开发的信息
  - 已公开的信息（非因接收方违约导致）
- [ ] **包含"交易信息"**：谈判事实、条款、保密协议签署本身、保密信息已提供给买方等
- [ ] **口头信息**：如包含，需在合理时间内书面确认（通常30日内）
- [ ] **披露例外**：法律法规、政府机构、证券交易所要求披露的情形

### 2.2 保密义务

- [ ] **使用限制**：仅用于评估潜在交易（"Permitted Purpose"）
- [ ] **接收方范围**：明确"代表"（Representatives）定义——员工、董事、高级职员、外部顾问（律师/会计师/投行）、融资方（银行）
- [ ] **传递要求**：按需知悉原则（need-to-know basis），传递前告知接收方保密义务
- [ ] **第三方义务**：确保代表承担同等保密义务（告知+书面承诺）
- [ ] **非复制**：不得复制保密信息（除评估所需除外）
- [ ] **分隔措施**：买方内部应建立保密墙（如投行团队与投资团队信息隔离）

### 2.3 保密期限

- [ ] **一般期限**：通常18-36个月（中国市场：2-3年）
- [ ] **商业秘密**：可约定永久保密（通常限于技术秘密、专利未公开信息）
- [ ] **终止后义务**：返还/销毁的时间要求（通常30-60日内）
- [ ] **残留信息条款**：电子副本、自动备份、法律合规留存的处理

### 2.4 竞业限制

- [ ] **限制范围**：地理范围、业务范围、时间范围是否合理
- [ ] **目的限定**：仅限制使用保密信息与标的公司竞争（不是全面竞业限制）
- [ ] **排除已有业务**：买方现有业务不应受 NDA 竞业限制

### 2.5 Standstill 条款（上市公司收购 NDA 常见）

- [ ] **核心内容**：在规定期限内未经卖方书面同意，不得直接或间接收购标的公司证券、寻求控制权变更、参与代理权征集
- [ ] **期限**：通常 6-18 个月（买方争取 ≤12 个月）
- [ ] **例外触发**：（1）标的被第三方公开要约；（2）标的董事会邀请买方参与竞价；（3）标的重大资产出售
- [ ] **标志注意**：Standstill 限制并不阻止买方与标的股东对话——除非明确限制

### 2.6 禁止招揽/非挖角

- [ ] **禁止招揽**：不得招揽标的公司员工（通常持续 12-24 个月，从签约日或谈判终止日起）
- [ ] **范围界定**：仅限于与交易有接触的员工，还是扩展到全公司？
- [ ] **例外情形**：通过公开招聘渠道/猎头非定向搜索的例外（须有）
- [ ] **与竞业的边界区分**：非招揽是限制挖人，竞业是限制业务竞争，两者独立
- [ ] **管理层例外**：买方关注——若谈判终止后标的公司关键人员主动联系买方，是否受限于非招揽？建议明确排除

### 2.7 返还/销毁条款

- [ ] **返还/销毁选择**：买方选择返还或销毁
- [ ] **时限**：终止后 30-60 日内
- [ ] **确认函**：是否要求出具销毁确认函？是否要求内部法务/外部律师签署？
- [ ] **信息返还的实操难点**：
  - 电子副本残留（系统自动备份、邮件服务器留存）
  - 买方内部分析人员脑中的知识（"已存入记忆的信息"）
  - 合规留存（上市公司需保留特定记录）
- [ ] **实操建议**：在 NDA 中加入"电子备份系统自动生成的一副本可不销毁，但不得访问或使用"

### 2.8 救济条款

- [ ] **禁令救济**：明确可申请禁令（Injunction / Specific Performance），无需证明实际损害
- [ ] **损害赔偿**：赔偿范围和计算方式（直接损失 vs. 间接损失）
- [ ] **责任上限**：是否有赔偿上限？若有，买方关注——上限不应低于交易对价的 1-3%
- [ ] **保证金**：是否要求缴纳保证金才能申请禁令？

### 2.9 其他条款

- [ ] **适用法律**：选择对己方有利的法律
- [ ] **争议解决**：仲裁（HKIAC/SIAC）vs. 诉讼。仲裁保密性好、可执行性强（纽约公约）
- [ ] **管辖权**：专属管辖或非专属
- [ ] **转让限制**：不得随交易转让（未经对方同意）
- [ ] **语言**：中英双语版本，约定冲突时以哪种语言为准
- [ ] **完整协议**：是否构成完整约定，是否排除了前期口头沟通

## 3. 背靠背保密协议（Back-to-Back NDA）

当项目组已与客户签署保密协议，对外与投资者签署时：

- [ ] **保密期限对齐**：不短于与客户间约定的期限（否则客户信息在投资者手中"提前脱密"）
- [ ] **信息范围一致**：不超出客户授权范围（超出部分需客户补充授权）
- [ ] **资料销毁对齐**：投资者销毁要求与客户间约定一致
- [ ] **代表定义对齐**：确保投资者方代表范围不超出客户授权
- [ ] **免责条款**：在客户 NDA 中加入一条"项目组与投资者签署 NDA，且投资者保密义务不低于本协议标准"

## 4. 跨境 NDA 特别注意

### 4.1 适用法律选择

| 交易背景 | 推荐法律 | 理由 |
|---------|---------|------|
| 纯国内交易 | 中国法 | 成本最低、最易执行 |
| 跨境交易（中-英/美/港） | 英国法或香港法 | 国际惯例、仲裁执行性强 |
| 标的在第三方国家 | 标的所在国法律 | 可能为东道国法律硬性要求 |

### 4.2 争议解决

- **仲裁优先**（保密性好，纽约公约覆盖170+缔约国）
  - 推荐机构：HKIAC（香港）、SIAC（新加坡）、ICC（巴黎）
  - 推荐地：香港或新加坡
- **诉讼辅选**：标的所在国法院诉讼（如印尼法院）

### 4.3 语言与翻译

- 中英双语版本
- 约定冲突时以哪种语言版本为准
- 避免使用机器翻译，法律术语不可直接翻译（如 security vs. guarantee）

---

## 5. 快速自检清单

签署 NDA 前，逐项确认：

- [ ] 己方是买方（信息接收方）还是卖方（信息披露方）？
- [ ] 保密信息范围和排除项是否合理？
- [ ] 使用限制是否限于评估交易（不过度限制内部团队正常运作）？
- [ ] 保密期限与交易时间线是否匹配（不早于交易结束前到期）？
- [ ] 如果有 Standstill，是否限制了己方的不合理？
- [ ] 非招揽/非挖角条款的范围是否合理？
- [ ] 返还条款中的"副本留存"是否对己方合理？
- [ ] 争议解决条款是否对己方有利？
- [ ] 是否涉及背靠背 NDA？（如涉及，检查对齐性）
