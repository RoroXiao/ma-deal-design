# 风险评估框架

> **适用场景**：尽调完成后 → 风险发现系统化分级（四步法+两阶段评估）→ 风险量化（发生概率×影响程度）→ 缓释策略矩阵 → 反向嵌入交易文件（earn-out/escrow/indemnity/Conditions Precedent）。**核心受众**：交易团队、尽调项目经理、风险委员会。**使用方法**：所有尽调发现录入风险台账 → 分配给维度打分 → 生成热力图 → 逐条匹配缓释措施。
> **配套文件**：`assets/04-risk-assessment-matrix.xlsx` — 可填列的风险评估矩阵工作簿

---

## 1. 方法论概览

并购风险评估的本质不是"找问题"，而是回答三个问题：

1. **哪些风险影响交易的可行性？** → 决定做不做
2. **哪些风险影响交易的对价和条款？** → 决定怎么做、多少钱
3. **哪些风险影响投后整合的成功率？** → 决定交割后做什么

### 1.1 四步核心流程

```
Step 1: 风险识别 (Risk Identification)
  └── 建立风险清单 → 跨维度交叉验证 → 形成主风险列表

Step 2: 风险分析 (Risk Analysis)
  └── 单一风险：发生概率(P) × 影响程度(Q) = 风险程度(R)
  └── 整体风险：综合指数 V = ∑(权重I × 风险程度R)
  └── 定性 + 定量双轨并行

Step 3: 风险评级 (Risk Classification)
  └── 单一风险分级：重大 / 较大 / 一般 / 较小 / 微小
  └── 整体风险等级：A级(不予实施) / B级(有条件实施) / C级(可实施)
  └── 跨境项目追加：国别风险独立评估

Step 4: 风险应对 (Risk Treatment)
  └── 四种策略：回避 → 抑制 → 转移 → 承担
  └── 高风险 → 交易条款映射
  └── 中低风险 → 投后管理计划
```

### 1.2 两阶段评估机制（推荐用于大型/跨境交易）

| 阶段 | 时间点 | 信息来源 | 输出 |
|------|--------|---------|------|
| **初步评估** | 尽调中期（首轮资料+管理层访谈完成后） | 管理层陈述、首轮资料、公开信息 | 风险热力图 + 重点尽调方向调整 |
| **最终评估** | 尽调结束、SPA谈判前 | 完整尽调报告、补充验证、第三方函证 | 最终风险等级 + 交易条款建议 + 投后管理重点 |

> 初步评估的作用不是在尽调做了一半时交一份不完整的报告，而是**用评估结论反向指导剩余尽调的资源分配**——高风险领域追加验证，低风险领域简化收尾。

## 2. 风险分类全景目录

以下分类适用于跨境并购。国内并购可省略"国别/政治/外汇"维度。

### 2.1 大类目录

| 大类 | 名称 | 覆盖范围 | 跨境特有 |
|:---:|------|---------|:---:|
| A | 政治与国别风险 | 政局稳定性、征收/国有化、政府违约、战争暴乱、双边关系 | ✓ |
| B | 宏观经济风险 | 经济增速、通货膨胀、利率、汇率管制 | ✓ |
| C | 法律与合规风险 | 外资准入、反垄断、行业许可、诉讼、知识产权、反腐败/制裁 | — |
| D | 市场与竞争风险 | 市场供需、价格波动、竞争格局、客户集中度、技术替代 | — |
| E | 财务风险 | 盈利质量、债务与流动性、营运资金、关联交易、表外负债 | — |
| F | 税务风险 | 历史欠税、税收优惠到期、转让定价、跨境预提税、税务稽查 | — |
| G | 运营与技术风险 | 产能真实性、设备老化、供应链、技术落后、IT/数据安全 | — |
| H | 劳工与社区风险 | 工会、合格劳动力、劳务派遣合规、社区关系、文化冲突 | ✓ |
| I | ESG与环境风险 | 环境许可、污染、生态修复义务、碳排放、安全生产 | — |
| J | 交易结构风险 | 股权质押、控制权变更条款、交割条件不确定性、分手费 | — |
| K | 估值与定价风险 | 假设激进程度、折现率合理性、可比交易参考性、正常化调整幅度 | — |
| L | 投后整合风险 | 文化融合、管理层留任、系统对接、客户保留、协同效应实现 | — |

### 2.2 风险识别清单（启动时逐项审查）

**A. 政治与国别风险**
- 东道国政治制度稳定性（选举周期、权力交接风险）
- 征收/国有化历史及法律保护
- 政府契约精神（过往违约记录）
- 恐怖主义/武装冲突风险
- 母国-东道国双边关系（投资保护协定、外交紧张）
- 国际制裁风险（SDN/UN/EU/UK名单）

**B. 宏观经济风险**
- GDP增速趋势及对业务的影响
- 通货膨胀对成本结构的影响
- 利率走势对债务成本的影响
- 汇率波动对报表折算和现金流的影响
- 外汇管制（利润汇出限制、强制结汇）

**C. 法律与合规风险**
- 外资准入限制（负面清单、持股比例上限）
- 反垄断/经营者集中审查
- 行业许可证照完整性
- 重大诉讼/仲裁（已知和潜在）
- 知识产权权属
- 反腐败/反贿赂合规（FCPA, UK Bribery Act, 本地反贪法）
- 数据/网络安全合规

**D. 市场与竞争风险**
- 行业需求趋势（增长/平稳/衰退）
- 竞争格局变化（新进入者、替代品）
- 客户集中度（Top 3客户收入占比）
- 供应商依赖度
- 价格周期波动
- 技术替代风险

**E. 财务风险**
- 盈利质量（非经常性损益占比）
- 债务结构（短期vs长期、浮动vs固定利率）
- 融资协议交叉违约条款
- 重大关联交易依赖
- 表外承诺与或有负债
- 资金归集安排对独立运营的影响

**F. 税务风险**
- 历史期间税务合规（各税种申报及缴纳）
- 税收优惠法律依据及到期时间
- 转让定价文档完整性
- 跨境预提税成本
- 可结转税务亏损的真实性和可用性

**G. 运营与技术风险**
- 实际产能vs设计产能差距
- 关键设备服役年限和状态
- 单一供应商依赖
- 技术路线是否面临淘汰
- 信息系统安全和灾备

**H. 劳工与社区风险**
- 工会组织化程度及罢工历史
- 合格劳动力供给
- 劳务派遣比例合规
- 当地社区关系（用地、就业、环保承诺）
- 中方vs本地员工文化融合

**I. ESG与环境风险**
- 环境许可证完整性
- 历史环境违规及未整改问题
- 生态修复/闭坑义务
- 碳排放合规
- 安全生产许可及事故历史

**J. 交易结构风险**
- 目标股权是否存在质押/冻结
- 控制权变更是否触发合同终止/加速到期
- 少数股东保护条款（随售权、优先购买权）
- 监管审批不确定性
- 交易保护条款（分手费、反向分手费）

**K. 估值与定价风险**
- 财务预测关键假设的激进程度
- 折现率是否反映国别风险溢价
- 可比交易/可比公司选择偏差
- 正常化调整的合理性
- 终值占比是否过高

**L. 投后整合风险**
- 管理层留任意愿与激励机制
- 企业文化差异
- 客户/供应商流失风险
- 系统与流程对接难度
- 协同效应实现的时间与幅度不确定性

## 3. 量化评估方法

### 3.1 单一风险评估：P × Q = R 矩阵

**风险概率（P）分级标准：**

| 等级 | 概率区间 | 定性描述 |
|------|:------:|---------|
| 很高 | 81%~100% | 几乎确定发生 |
| 较高 | 61%~80% | 很有可能发生 |
| 中等 | 41%~60% | 有可能发生 |
| 较低 | 21%~40% | 发生可能性较小 |
| 很低 | 0%~20% | 发生可能性很小 |

**影响程度（Q）分级标准：**

| 等级 | 程度区间 | 定性描述 |
|------|:------:|---------|
| 严重 | 81%~100% | 对交易目标实现造成重大损害，需付出极大代价长期消除 |
| 较大 | 61%~80% | 对交易目标造成较大损害，需较长时间、较大代价消除 |
| 中等 | 41%~60% | 对交易目标造成一定损害，需投入一定资源消除 |
| 较小 | 21%~40% | 在一定范围内有负面影响，短期内可消除 |
| 微小 | 0%~20% | 负面影响很小，通过解释和沟通即可消除 |

**风险程度（R）= P × Q，快速对照表：**

|  | 严重 (0.9) | 较大 (0.7) | 中等 (0.5) | 较小 (0.3) | 微小 (0.1) |
|---|:---:|:---:|:---:|:---:|:---:|
| **很高 (0.9)** | 重大 0.81 | 较大 0.63 | 较大 0.45 | 一般 0.27 | 较小 0.09 |
| **较高 (0.7)** | 较大 0.63 | 较大 0.49 | 一般 0.35 | 一般 0.21 | 较小 0.07 |
| **中等 (0.5)** | 较大 0.45 | 一般 0.35 | 一般 0.25 | 较小 0.15 | 较小 0.05 |
| **较低 (0.3)** | 一般 0.27 | 一般 0.21 | 较小 0.15 | 较小 0.09 | 微小 0.03 |
| **很低 (0.1)** | 较小 0.09 | 较小 0.07 | 较小 0.05 | 微小 0.03 | 微小 0.01 |

**风险程度分级：**

| 等级 | R值区间 | 响应要求 |
|------|:------:|---------|
| 🔴 **重大** | R > 0.64 | 必须采取有效的防范化解措施。影响交易可行性判断。 |
| 🟠 **较大** | 0.36 < R ≤ 0.64 | 应采取积极的防范化解措施。影响交易对价或条款。 |
| 🟡 **一般** | 0.16 < R ≤ 0.36 | 需采取一定的防范化解措施。纳入投后管理。 |
| 🟢 **较小** | 0.04 < R ≤ 0.16 | 一般不影响决策可行性。可接受或通过保险转移。 |
| ⚪ **微小** | R ≤ 0.04 | 可接受。关注但不需专门措施。 |

> **简化版打分法**（用于初步/快速评估）：P 和 Q 各用 1-5 分，R = P × Q。R ≥ 16 为重大，R ≥ 10 为重要，其余为一般。

### 3.2 整体风险评估：综合指数法

当需要评估项目整体风险等级时，使用综合风险指数 V：

**V = Σ (Iᵢ × Rᵢ)**

- Iᵢ = 第i个风险因素在所有风险中的权重（ΣI=1）
- Rᵢ = 第i个风险因素的程度值

权重通过专家评分取算术平均确定。

**整体风险等级评判：**

| 等级 | V 值 | 含义 |
|------|:----:|------|
| A级 | V > 0.64 | 风险程度重大，建议不予实施或需根本性调整方案 |
| B级 | 0.36 ≤ V ≤ 0.64 | 风险程度较大，建议调整方案降低风险后实施，或采取有效防范措施后实施 |
| C级 | V < 0.36 | 风险程度一般或较低，可实施，做好解释沟通、妥善处理合理诉求后实施 |

**多维度辅助评判**（达到任一条件即可认定对应等级）：

| 评判维度 | A级 | B级 | C级 |
|---------|-----|-----|-----|
| 重大单一风险数量 | ≥2个 | 1个 | 0个 |
| 较大单一风险数量 | ≥5个 | 2-4个 | 0-1个 |
| 风险事件可能触发 | 冲击要害部门、人员伤亡、大规模集会、境外势力介入 | 进京集访、极端行为扬言、阻断交通 | 一般上访、静坐、散布信息 |

## 4. 风险应对策略

### 4.1 四种基本策略

| 策略 | 定义 | 适用场景 | 典型操作 |
|------|------|---------|---------|
| **风险回避** | 主动放弃或拒绝实施 | 重大风险无法有效缓释 | 退出交易、排除特定资产/业务板块 |
| **风险抑制** | 降低发生概率或减少损失 | 大部分可缓解的风险 | 增加尽调深度、设置交割先决条件、TPA |
| **风险转移** | 全部或部分转移至他方 | 可保险/可赔偿的风险 | 购买保险、卖方赔偿条款、escrow |
| **风险承担** | 制定应急预案，自行承担 | 低风险、缓释成本高于风险本身 | 准备专项储备金、制定应急预案 |

### 4.2 风险 → 交易条款映射（核心实战输出）

这是风险评估与交易文件之间的桥梁——每项高风险发现，都应在 SPA 中有对应的条款安排：

| 风险发现 | 条款映射 | 具体安排建议 |
|---------|---------|------------|
| 重大诉讼未决 | 赔偿条款 + Escrow | 卖方全额赔偿 + 冻结对价15-20%，覆盖诉讼期间 |
| 历史税务漏洞 | Tax Indemnity | 单独税务赔偿条款，索赔期延长至6-7年（远超一般陈述保证期限） |
| 盈利质量存疑 | Earn-out + 降低现金对价 | 2-3年 earn-out，与未来 EBITDA/收入挂钩 |
| 核心资产权属瑕疵 | 交割先决条件 | 必须在交割日前完成确权/补证，否则买方有权终止 |
| 客户集中度高 | 对价调整机制 | 若交割后12个月内 Top 3 客户流失，按比例下调未付对价 |
| 关键人依赖 | 留任协议 + 竞业禁止 | Lock-up 2-3年, Non-compete 2年，覆盖核心市场 |
| 环境修复义务 | 专项赔偿 + Escrow | Special indemnity, escrow 覆盖预估修复费120% |
| 关联交易依赖 | 过渡期服务协议 (TSA) | TSA 6-12个月，明确关键服务定价基准和终止机制 |
| 控制权变更触发违约 | 卖方协助取得豁免 | 列入交割先决条件，或由卖方赔偿引起的提前还款损失 |
| 股权质押未解除 | 交割先决条件 | 必须在签约前/交割前完成解押并提供证明 |

### 4.3 风险缓释动态跟踪

```
初步评估 (尽调中期)
  │
  ├── 识别高风险 → 追加尽调验证
  │    └── example: 收入确认质量存疑 → 追加大额销售合同抽查+客户函证
  │
  ├── 识别中风险 → 补充管理层访谈谈透
  │    └── example: 关联交易依赖 → 访谈了解市场替代可行性
  │
  └── 识别低风险 → 标准流程收尾
       └── example: 常规社保合规 → 确认缴纳基数和比例，不做深度追溯

最终评估 (SPA谈判前)
  │
  ├── 原"重大风险" → 管理层已采取缓释措施 → 评估是否降级
  │    └── 若未降级 → 必须反映在交易条款中
  │
  ├── 原"较大风险" → 部分已缓释 → 重新评估剩余风险敞口
  │
  └── 新增发现 → 纳入最终风险矩阵
```

## 5. 风险评估报告标准结构

一份完整的并购风险评估报告应包含以下章节：

```
1. 项目概况（不超过3页）
   1.1 交易背景与标的简介
   1.2 收购方案概要
   1.3 交易关键假设

2. 评估方法与工作范围
   2.1 评估目的和原则（独立公正 / 全面客观 / 科学评估）
   2.2 评估方法（p×q矩阵 / 打分和积法 / 综合指数法）
   2.3 信息来源与局限性声明
   2.4 评估团队构成

3. 风险评估总体情况
   3.1 风险总览（热力图或汇总表）
   3.2 总体评估结论
   3.3 重点风险提示（Executive Summary 级别）

4. 详细风险评估（按类别逐章）
   4.1 政治与国别风险
   4.2 宏观经济风险
   4.3 法律与合规风险
   4.4 市场与竞争风险
   4.5 财务风险
   4.6 税务风险
   4.7 运营与技术风险
   4.8 劳工与社区风险
   4.9 ESG与环境风险
   4.10 交易结构风险
   4.11 估值与定价风险
   4.12 投后整合风险

   [每类风险按以下格式逐项描述:]
   风险因素 | 风险描述 | 风险概率(P) | 影响程度(Q) | 风险程度(R) | 缓释建议

5. 风险 → 交易条款映射
   5.1 对价的调整机制
   5.2 交割先决条件
   5.3 卖方陈述与保证
   5.4 赔偿条款
   5.5 过渡期安排
   5.6 分手费与保护条款

6. 风险防范与缓释方案
   6.1 交割前缓释措施
   6.2 过渡期管理
   6.3 投后整合风险应对
   6.4 风险应急预案

7. 结论与建议
```

## 6. 跨境交易特别提示

### 6.1 国别风险独立评估

跨境交易不应将国别风险与其他风险混同打分——国别风险是底层约束，应先评估国别风险是否可接受，再评估项目风险。

**国别风险快速筛查清单：**
- [ ] 是否与中国签有双边投资保护协定（BIT）？
- [ ] 该国过去5年是否有对中国投资的征收/歧视案例？
- [ ] 该国是否在 FATF 灰/黑名单上？
- [ ] 该国汇率是否实行自由浮动？是否有强制结汇要求？
- [ ] 利润/分红汇出是否有额度限制或审批要求？
- [ ] 是否有本地化用工/采购强制比例要求？
- [ ] 土地/矿权等关键资产的外资持有是否受限制？

### 6.2 多法域协调

- 母公司 + 各运营子公司所在国，可能需要分别出具当地法律意见
- 不同法域下"重大不利影响（MAE/MAC）"的认定标准不同，需在 SPA 中明确定义
- 跨境担保/抵押的登记和执行在不同法域下的有效性需要单独确认

### 6.3 汇率风险的三层处理

1. **报表层面**：本币报表→人民币折算，货币贬值导致账面亏损
2. **现金流层面**：当地币收入 vs 美元/人民币采购成本，汇率波动影响实际利润
3. **对价层面**：若交易以美元计价而标的收入以当地币定价，买卖双方对"合理汇率"的博弈

对应策略：远期锁汇、美元定价+当地币联动调整条款、在估值模型中嵌入汇率敏感性分析。

## 7. 快速启动指南

### 7.1 小型/国内并购（精简版）

1. 打开 `assets/04-risk-assessment-matrix.xlsx`，在 Sheet "风险清单"中逐项勾选适用风险
2. 对适用风险逐一打分（P和Q各1-5分），自动生成风险热力图
3. 标记为"重大"的风险，填入 Sheet "缓释与条款映射"，一对一给出 SPA 条款建议
4. 在 Sheet "仪表板"中查看整体风险分布

### 7.2 大型/跨境并购（完整版）

1. 组建多领域专家团队（至少覆盖：国别/法律/财务/税务/技术/ESG）
2. 按本节第5章报告结构展开初步评估
3. 初步评估结论 → 调整尽调方向 → 完成最终评估
4. 最终评估结论 → 谈判策略建议 → SPA 条款清单
5. 生成最终风险评估报告
